# Накопление потока (Flow Accumulation)

## 1. Введение и теоретические основы

Накопление потока (англ. *flow accumulation*) — это ключевая операция гидрологического анализа рельефа, направленная на **расчёт количества воды (или площади водосбора), стекающей в каждую ячейку цифровой модели рельефа (ЦМР)**. Данная операция строится на основе растра направления стока (*flow direction*) и моделирует процесс концентрации поверхностного стока от вершин к низинам.

С гидрологической точки зрения, значение накопления в ячейке пропорционально:
- количеству вышестоящих ячеек, стекающих в неё,
- площади водосбора, дренирующей в данную точку.

Математически, для каждой ячейки \( i \):
\[
A_i = 1 + \sum_{j \in U(i)} A_j
\]
где \( U(i) \) — множество ячеек, стекающих в \( i \).

В контексте геоинформационных систем flow accumulation служит основой для:
- автоматического выделения речной сети,
- определения главных водотоков,
- расчёта площади водосбора,
- оценки эрозионного потенциала.

Методологически данная операция относится к классу **гидрологических преобразований растровых поверхностей** и требует **предварительно рассчитанного растра направления стока**.

## 2. Ключевые слова и семантические триггеры

накопление потока, flow accumulation, площадь водосбора, гидрологический анализ, QGIS Flow Accumulation, ArcMap Flow Accumulation

## 3. Область применения

- **Гидрология**: автоматическое выделение речной сети и водотоков.
- **Экология**: определение зон с высоким стоком для охраны водных ресурсов.
- **Сельское хозяйство**: оценка эрозионной активности склонов.
- **Градостроительство**: моделирование зон концентрации ливневых вод.
- **Лесное хозяйство**: прогнозирование путей распространения паводков.
- **Управление ЧС**: выявление потенциальных русел при сходе селей или паводков.

## 4. Входные данные

- **Растр направления стока** (flow direction), полученный после *Fill Sinks* → *Flow Direction*.
- **Система координат**: проекция должна быть в **линейных единицах (метрах)**.
- **Разрешение**: влияет на абсолютные значения накопления (в ячейках или м²).
- **Опционально**: растр весов (например, осадки, почвенная проницаемость).

> ⚠️ **Важно**: Без корректного растра направления стока результат будет некорректным. Все ячейки должны иметь определённое направление.

## 5. Выходные данные

- Новый растр того же разрешения и экстента, что и исходный.
- Значения ячеек — **число вышестоящих ячеек** (по умолчанию) или **площадь водосбора в м²** (если задано разрешение).
- Тип данных: обычно **int32** или **float32**.
- Ячейки-истоки (верховые) имеют значение **1**, устья — максимальные значения.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Растры → Анализ → Инструменты гидрологии → Накопление потока...
- **Альтернатива**: использовать **GRASS r.accum.flow** или **SAGA Flow Accumulation** через Processing Toolbox.
- **Параметры**:
  - Input layer: растр направления стока,
  - Output: путь к выходному файлу,
  - Weight raster: опциональный растр весов (например, осадки).
- **Особенности**: 
  - Поддерживает взвешенное накопление,
  - Результат можно сразу использовать для выделения речной сети (через порог),
  - Автоматически определяет единицы измерения CRS.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Flow Accumulation** входит в состав расширения **Spatial Analyst**, которое должно быть активировано (*Customize → Extensions → Spatial Analyst*).

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Spatial Analyst Tools → Hydrology → Flow Accumulation**.

#### Основные параметры:
- **Input flow direction raster**: растр направления стока.
- **Output accumulation raster**: путь к выходному файлу.
- **Input weight raster**: опциональный растр весов (например, `precipitation.tif`).
- **Data type**: тип выходных данных (`INTEGER` или `FLOAT`).

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 интерфейс менее гибкий — нет предварительного просмотра.
- Начиная с 10.7, улучшена обработка больших ЦМР (>10 000 × 10 000 пикселей).
- При работе с высоким разрешением возможны ошибки нехватки памяти — рекомендуется использовать **scratch workspace** на быстром диске.
- Результат автоматически добавляется на карту и может быть использован для **Stream Order** или **Watershed**.

#### Типичные сценарии:
- **Выделение речной сети**:  
  Flow Accumulation → Reclassify (порог = 1000 ячеек) → Stream to Feature.
- **Оценка эрозии**:  
  Высокие значения накопления → зоны с высоким стоком → риск эрозии.

## 8. Ограничения и особенности

1. **Требует корректного Flow Direction**: без него результат будет ошибочным.
2. **Чувствителен к разрешению**: низкое разрешение сглаживает детали, высокое — создаёт шум.
3. **Не учитывает инфильтрацию**: модель предполагает 100% поверхностный сток.
4. **Производительность**: время выполнения растёт с увеличением размера ЦМР.
5. **Интерпретация**: абсолютные значения зависят от разрешения — для сравнения используйте относительные пороги.
