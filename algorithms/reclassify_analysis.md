# Переклассификация растровых значений (Reclassify)

## 1. Введение и теоретические основы

Переклассификация (англ. *reclassify*) — это фундаментальная операция растрового анализа, направленная на **замещение исходных значений ячеек новыми значениями** в соответствии с заданными правилами или таблицей соответствия. Данная операция позволяет преобразовать количественные данные (например, высоту, уклон, плотность) в качественные категории (например, «низкий», «средний», «высокий»), а также упростить сложные растрy для последующего анализа или визуализации.

С математической точки зрения, reclassify представляет собой **кусочно-постоянную функцию отображения**:  
\[
R_{\text{new}}(x, y) = f(R_{\text{old}}(x, y))
\]  
где \( f \) — пользовательская функция, определённая либо как диапазон значений → новое значение, либо как точное соответствие (1:1).

В контексте геоинформационных систем переклассификация служит ключевым инструментом для:
- подготовки данных к моделям многокритериальной оценки (MCE),
- создания бинарных масок (например, «подходит / не подходит»),
- стандартизации данных из разных источников,
- упрощения легенд для картографической визуализации.

Методологически reclassify относится к классу **локальных (точечных) операций над растровыми данными**, где значение выходной ячейки зависит только от значения входной ячейки, без учёта окружения.

## 2. Ключевые слова и семантические триггеры

переклассификация, reclassify, перекодировка, категоризация, группировка значений, QGIS Reclassify, ArcMap Reclassify

## 3. Область применения

- **Оценка пригодности территорий**: преобразование уклона (градусы) в категории: 0–5° → 1 (подходит), 5–15° → 2 (ограниченно), >15° → 3 (не подходит).
- **Экологический мониторинг**: перекодировка NDVI в классы растительности (вода, пустыня, лес, сельхозугодья).
- **Градостроительство**: создание бинарной маски застройки (1 — здания, 0 — всё остальное).
- **Анализ рисков**: преобразование расстояния до дороги в уровни доступности.
- **Подготовка данных для моделей**: стандартизация всех факторов к шкале 1–5 перед взвешиванием.
- **Упрощение легенд**: сокращение числа классов цветовой шкалы для печати.

## 4. Входные данные

- **Исходный растр** (GeoTIFF, GRID, IMG) с числовыми значениями (целыми или дробными).
- **Правила переклассификации**, задаваемые одним из способов:
  - Диапазоны: `[0–100] → 1`, `[101–200] → 2`, ...
  - Точечные соответствия: `1 → 10`, `2 → 20`, ...
  - Условные выражения: `if value < 50 then 0 else 1`.
- **Обработка NoData**: указание, сохранять ли NoData или заменять на конкретное значение.

> ⚠️ **Важно**: Все значения, не охваченные правилами, по умолчанию становятся NoData (если не указано иное).

## 5. Выходные данные

- Новый растровый слой того же разрешения и экстента, что и исходный.
- Значения ячеек — новые, согласно правилам переклассификации.
- Тип данных: обычно **int16** или **uint8** (для категориальных данных).
- NoData-значения обрабатываются в соответствии с настройками.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Растры → Анализ → Инструменты переклассификации → Переклассифицировать по таблице...
- **Параметры**:
  - Input raster layer: исходный растр,
  - Reclassification table: таблица в формате CSV или встроенная форма,
  - Output raster: путь к выходному файлу,
  - NoData handling: опция «сохранить как NoData» или «заменить».
- **Особенности**: 
  - Поддерживает как диапазоны, так и точечные значения,
  - Можно загрузить правила из файла,
  - Результат можно сразу стилизовать через *Paletted/Unique values*.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Reclassify** входит в состав расширения **Spatial Analyst**, которое должно быть активировано (*Customize → Extensions → Spatial Analyst*).

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Spatial Analyst Tools → Reclass → Reclassify**.

#### Основные параметры:
- **Input raster**: исходный растр.
- **Reclass field**: поле (обычно Value) для переклассификации.
- **Remap**: интерактивная таблица, где можно:
  - Задавать диапазоны (например, 0–100 → 1),
  - Удалять ненужные значения (ставя NoData),
  - Копировать исходные значения (для частичной переклассификации).
- **Output raster**: путь к выходному файлу.
- **Missing values**: как обрабатывать значения, не вошедшие в правила.

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 интерфейс таблицы менее интуитивен — требуется ручной ввод диапазонов.
- Начиная с 10.7, улучшена работа с дробными значениями и большими диапазонами.
- При работе с высоким разрешением возможны ошибки нехватки памяти — рекомендуется использовать **scratch workspace** на быстром диске.
- Результат автоматически добавляется на карту; его можно сразу использовать в **Weighted Overlay** или других моделях.

#### Типичные сценарии:
- **Оценка уклона**:  
  Исходный растр: slope.tif (0–90°) →  
  Правила: 0–5 → 1, 5–15 → 2, 15–30 → 3, >30 → NoData
- **Бинаризация**:  
  Исходный растр: distance_to_road.tif →  
  Правила: 0–500 → 1, >500 → 0

## 8. Ограничения и особенности

1. **Требование к типу данных**: работает только с **числовыми растрaми** (не с текстовыми).
2. **Потеря информации**: переклассификация необратима — исходные значения теряются.
3. **Чувствительность к границам диапазонов**: важно точно указывать, включены ли границы (например, 0–100 или 0–99.999).
4. **NoData-обработка**: если не настроена явно, может привести к потере данных.
5. **Не учитывает пространственный контекст**: reclassify — чисто атрибутивная операция.
