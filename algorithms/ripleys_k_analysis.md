# Анализ точечных паттернов (Point Pattern Analysis, Ripley’s K)

## 1. Введение и теоретические основы

Анализ точечных паттернов (англ. *point pattern analysis*) — это метод пространственной статистики, направленный на **оценку характера распределения точечных явлений**: случайное, кластеризованное или регулярное (равномерное). Основой количественного анализа является функция **Рипли K (Ripley’s K-function)**, предложенная Брайаном Рипли в 1976 году, которая измеряет среднее число соседей в зависимости от радиуса окружности вокруг каждой точки.

Формально, функция K определяется как:
\[
K(r) = \frac{1}{\lambda} E[\text{число точек в радиусе } r \text{ от произвольной точки}]
\]
где \( \lambda \) — интенсивность точечного процесса (средняя плотность точек).

Для однородного пуассоновского процесса (случайное распределение):
\[
K_{\text{случайное}}(r) = \pi r^2
\]

Интерпретация:
- **\( K(r) > \pi r^2 \)** → кластеризация (точки группируются),
- **\( K(r) < \pi r^2 \)** → регулярность (точки избегают друг друга),
- **\( K(r) ≈ \pi r^2 \)** → случайность.

Часто используется преобразованная форма **L(r)** для линеаризации:
\[
L(r) = \sqrt{\frac{K(r)}{\pi}} - r
\]
где \( L(r) > 0 \) — кластеризация, \( L(r) < 0 \) — регулярность.

В контексте геоинформационных систем Ripley’s K служит ключевым инструментом для:
- проверки гипотез о механизмах размещения объектов,
- сравнения распределений разных явлений,
- обоснования использования моделей точечных процессов.

Методологически данный анализ относится к классу **методов второго порядка точечных процессов** и требует наличия **точечного слоя без атрибутивных весов** (или с одинаковыми весами).

## 2. Ключевые слова и семантические триггеры

точечные паттерны, point pattern analysis, Ripley’s K, функция Рипли, K-функция, QGIS Ripley’s K, ArcMap Spatial Statistics

## 3. Область применения

- **Экология**: анализ распределения деревьев в лесу (конкуренция vs. совместное выживание).
- **Эпидемиология**: проверка, случайно ли распределены случаи заболевания.
- **Криминология**: оценка, группируются ли преступления в пространстве.
- **Геология**: анализ размещения месторождений полезных ископаемых.
- **Урбанистика**: изучение распределения общественных пространств или магазинов.
- **Биогеография**: моделирование ареалов видов.

## 4. Входные данные

- **Точечный векторный слой** (например, деревья, преступления, случаи заболевания).
- **Область исследования (study area)**: полигональный слой, ограничивающий анализ (обязателен для корректного учёта краевых эффектов).
- **Диапазон радиусов**: минимальный и максимальный радиус анализа (в единицах CRS).
- **Система координат**: желательно метрическая (для корректного задания радиуса в метрах).

> ⚠️ **Важно**: Без указания области исследования возможны **краевые искажения** (edge effects), так как точки у границы имеют меньше соседей.

## 5. Выходные данные

- **График функции L(r)** с доверительными интервалами (обычно ±95%).
- **Текстовый вывод**: «кластеризация», «регулярность» или «случайность».
- **Таблица значений K(r) и L(r)** для каждого радиуса.
- Возможность экспорта графика в PDF/PNG и таблицы в CSV.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Обработка → Инструментарий анализа → Point Pattern Analysis → Ripley’s K...
- **Требуется плагин**: **Spatial Statistics** или **PySAL** (встроен в Processing Toolbox).
- **Параметры**:
  - Input point layer: точечный слой,
  - Study area: полигональный слой области исследования,
  - Distance band min/max: диапазон радиусов,
  - Number of distance bands: количество шагов.
- **Особенности**: 
  - Автоматически корректирует краевые эффекты (метод «border correction»),
  - Строит график L(r) с доверительными интервалами,
  - Экспортирует результаты в таблицу и изображение.

### 6.2. ArcMap (версии 10.4–10.8)

ArcMap **не имеет прямого инструмента Ripley’s K** в стандартной поставке. Однако анализ можно выполнить:

#### Вариант A: Через **R или Python**
- Использовать скрипт на R (`spatstat` package) или Python (`PySAL`), вызываемый из ArcGIS через **Script Tool**.

#### Вариант B: Через **Multi-Distance Spatial Cluster Analysis (Ripley’s K)**
- Доступен в **Spatial Statistics Tools → Analyzing Patterns** (начиная с ArcGIS Pro; в ArcMap 10.4–10.8 — только через дополнительные модули или скрипты).

#### Особенности:
- В ArcMap 10.4–10.8 рекомендуется использовать **QGIS или внешние скрипты** для Ripley’s K.
- При использовании скриптов требуется установка **Python + PySAL** или **R + spatstat**.

#### Типичные сценарии:
- **Экологический анализ**:  
  Слой = деревья.shp, Область = лесной_массив.shp → K(r) показывает кластеризацию на расстоянии до 10 м.
- **Криминология**:  
  Слой = преступления.shp, Область = город.shp → случайное распределение на всех масштабах.

## 8. Ограничения и особенности

1. **Требование к данным**: работает только с **точечными слоями**.
2. **Обязательна область исследования**: без неё результат некорректен.
3. **Чувствительность к выбору радиуса**: слишком малый — шум, слишком большой — потеря локальных паттернов.
4. **Не учитывает атрибуты**: все точки считаются равнозначными (для взвешенного анализа — другие методы).
5. **Производительность**: время выполнения растёт квадратично с числом точек.
