# Анализ горячих точек (Hot Spot Analysis, Getis-Ord Gi*)

## 1. Введение и теоретические основы

Анализ горячих точек (англ. *hot spot analysis*) — это метод пространственной статистики, направленный на **выявление статистически значимых кластеров высоких («горячих») и низких («холодных») значений** в распределении атрибутивного признака по территории. Основой метода является статистика **Getis-Ord Gi\*** (Getis & Ord, 1992), которая оценивает, насколько значение в данной ячейке отличается от среднего значения в её окрестности с учётом пространственной автокорреляции.

Формально, для каждого объекта \( i \) вычисляется:
\[
G_i^* = \frac{\sum_{j=1}^{n} w_{ij} x_j - \bar{X} \sum_{j=1}^{n} w_{ij}}{S \sqrt{\frac{n \sum_{j=1}^{n} w_{ij}^2 - (\sum_{j=1}^{n} w_{ij})^2}{n-1}}}
\]
где:
- \( x_j \) — значение признака в объекте \( j \),
- \( w_{ij} \) — пространственный вес (обычно 1, если \( j \) в радиусе от \( i \), иначе 0),
- \( \bar{X}, S \) — среднее и стандартное отклонение по всему набору.

Результат интерпретируется через **z-оценку** и **p-значение**:
- **Высокая z-оценка (Gi\* > 1.96, p < 0.05)** → «горячая точка» (HH: high-high),
- **Низкая z-оценка (Gi\* < –1.96, p < 0.05)** → «холодная точка» (LL: low-low).

В контексте геоинформационных систем hot spot analysis служит ключевым инструментом для:
- выявления криминальных районов,
- анализа распространения заболеваний,
- оценки концентрации экономической активности,
- мониторинга экологических аномалий.

Методологически данный анализ относится к классу **локальных показателей пространственной автокорреляции (LISA)** и требует наличия **точечных или полигональных данных с количественным атрибутом**.

## 2. Ключевые слова и семантические триггеры

горячие точки, hot spot analysis, Getis-Ord Gi*, пространственная кластеризация, QGIS Hot Spot, ArcMap Hot Spot Analysis

## 3. Область применения

- **Криминология**: выявление районов с высокой концентрацией преступлений.
- **Эпидемиология**: обнаружение очагов заболеваний (например, COVID-19).
- **Экономика**: анализ кластеров ВВП, безработицы, цен на жильё.
- **Экология**: выявление зон с аномально высоким уровнем загрязнения.
- **Социология**: изучение пространственного неравенства (доходы, образование).
- **Градостроительство**: оценка доступности социальных услуг.

## 4. Входные данные

- **Векторный слой**: точечный или полигональный.
- **Атрибутивное поле**: числовое поле с анализируемым признаком (например, `crime_count`, `income`).
- **Пространственная матрица весов**: задаётся радиусом поиска (distance band) или числом соседей.
- **Система координат**: желательно метрическая (для корректного задания радиуса в метрах).

> ⚠️ **Важно**: Поле не должно содержать **отрицательных значений**, если анализ основан на частотах или плотностях (например, число преступлений). Для других признаков (температура, доход) допустимы любые числа.

## 5. Выходные данные

- Новый векторный слой с теми же геометриями.
- Атрибутивная таблица содержит поля:
  - `GiZScore` — z-оценка Getis-Ord,
  - `GiPValue` — p-значение,
  - `GiClass` — категория: `High-High`, `Low-Low`, `Not Significant`.
- Возможность визуализации через цветовую шкалу (красный — горячие, синий — холодные).

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Обработка → Инструментарий анализа → Hotspot Analysis (Getis-Ord Gi*)...
- **Требуется плагин**: **Spatial Statistics** или **PySAL** (встроен в Processing Toolbox).
- **Параметры**:
  - Input layer: исходный слой,
  - Input field: атрибутивное поле,
  - Distance band: радиус анализа (в единицах CRS),
  - Output: путь к выходному файлу.
- **Особенности**: 
  - Поддерживает только точечные данные (для полигонов — предварительно центроиды),
  - Использует PySAL для расчётов,
  - Результат можно сразу стилизовать по полю `GiClass`.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Hot Spot Analysis (Getis-Ord Gi*)** входит в состав расширения **Spatial Statistics Tools**, доступного через **ArcToolbox**.

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Spatial Statistics Tools → Mapping Clusters → Hot Spot Analysis (Getis-Ord Gi*)**.

#### Основные параметры:
- **Input Feature Class**: исходный слой.
- **Input Field**: атрибутивное поле.
- **Output Feature Class**: путь к выходному файлу.
- **Conceptualization of Spatial Relationships**: 
  - *INVERSE_DISTANCE*,
  - *FIXED_DISTANCE_BAND* (наиболее часто используется),
  - *CONTIGUITY_EDGES_ONLY* (для полигонов).
- **Distance Band**: радиус анализа (автоматически рассчитывается, но можно задать вручную).

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 интерфейс менее гибкий — нет предварительного просмотра.
- Начиная с 10.7, улучшена обработка больших наборов данных (>10 000 объектов).
- При работе с File Geodatabase результат более стабилен.
- Инструмент **автоматически определяет оптимальный радиус**, если он не задан.

#### Типичные сценарии:
- **Криминальная карта**:  
  Слой = преступления.shp, Поле = `count`, Радиус = 500 м → выявление горячих точек.
- **Экономический анализ**:  
  Слой = районы.shp, Поле = `median_income` → кластеры богатства/бедности.

## 8. Ограничения и особенности

1. **Требование к данным**: необходимо достаточное число объектов (>30) для статистической значимости.
2. **Чувствительность к радиусу**: слишком малый радиус — шум, слишком большой — потеря локальных кластеров.
3. **Не работает с категориальными данными**: требуется числовой атрибут.
4. **Производительность**: время выполнения растёт квадратично с числом объектов.
5. **Интерпретация**: наличие кластера ≠ причинно-следственная связь — требуется дополнительный анализ.
