# Построение изолиний (Contour) по цифровой модели рельефа

## 1. Введение и теоретические основы

Построение изолиний (англ. *contour*) — это фундаментальная операция растрового анализа, направленная на **создание векторных линий, соединяющих точки с одинаковыми значениями на непрерывной поверхности**, заданной растром. Наиболее распространённое применение — построение **горизонталей (изогипс)** по цифровой модели рельефа (ЦМР), где каждая линия представляет собой совокупность точек с одинаковой высотой над уровнем моря.

С математической точки зрения, изолиния является **линией уровня функции двух переменных** \( z = f(x, y) \), где \( z \) — значение в ячейке растрa (например, высота), а \( x, y \) — координаты. Алгоритмы построения контуров (например, *Marching Squares*) интерполируют значения между ячейками для повышения точности геометрии линий.

В контексте геоинформационных систем изолинии служат ключевым инструментом для:
- создания топографических карт,
- визуализации трёхмерных поверхностей на плоскости,
- анализа формы рельефа (водоразделы, замкнутые котловины),
- подготовки данных для гидрологического моделирования.

Методологически contour относится к классу **операций преобразования растра в вектор**, где результатом является линейный векторный слой.

## 2. Ключевые слова и семантические триггеры

изолинии, contour, горизонтали, изогипсы, линии уровня, ЦМР, DEM, QGIS Contour, ArcMap Contour

## 3. Область применения

- **Топографическая картография**: создание стандартных топокарт с горизонталями.
- **Геоморфология**: анализ форм рельефа (склоны, террасы, овраги).
- **Инженерные изыскания**: проектирование дорог, трубопроводов с учётом рельефа.
- **Сельское хозяйство**: планирование противоэрозионных мероприятий.
- **Туризм и рекреация**: подготовка карт для пешеходных и веломаршрутов.
- **Гидрология**: определение водоразделов и направления стока.

## 4. Входные данные

- **Цифровая модель рельефа (ЦМР)** в виде растрa (GeoTIFF, GRID, IMG) с числовыми значениями высоты.
- **Интервал изолиний** (contour interval): шаг между соседними линиями (например, 10 м, 50 м).
- **Базовая высота** (base contour): начальное значение (по умолчанию 0).
- **Система координат**: проекция должна быть в **линейных единицах (метрах)**.

> ⚠️ **Важно**: ЦМР не должна содержать NoData-значений в зоне интереса, так как это приведёт к разрывам в изолиниях.

## 5. Выходные данные

- Новый **линейный векторный слой** (shapefile или feature class).
- Атрибутивная таблица содержит поле **`ELEV`** (или `Contour`) с высотой каждой изолинии.
- Геометрия линий — интерполированная между ячейками растрa.
- Замкнутые изолинии представляют вершины или котловины.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Растры → Анализ → Инструменты анализа рельефа → Изолинии...
- **Параметры**:
  - Input layer: ЦМР,
  - Interval between contour lines: интервал (в единицах ЦМР),
  - Attribute name: имя поля высоты (по умолчанию `ELEV`),
  - Output: путь к выходному файлу.
- **Особенности**: 
  - Использует GDAL-реализацию алгоритма Marching Squares,
  - Автоматически определяет единицы измерения CRS,
  - Поддерживает дробные интервалы (например, 2.5 м).

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Contour** входит в состав расширения **Spatial Analyst**, которое должно быть активировано (*Customize → Extensions → Spatial Analyst*).

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Spatial Analyst Tools → Surface → Contour**.

#### Основные параметры:
- **Input raster**: цифровая модель рельефа.
- **Contour interval**: интервал между изолиниями (в единицах высоты).
- **Base contour**: базовая высота (по умолчанию 0).
- **Z factor**: коэффициент для преобразования вертикальных единиц (если высота в футах, а проекция в метрах).
- **Output polyline features**: путь к выходному векторному файлу.

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 инструмент может работать медленно с высоким разрешением (>5 м).
- Начиная с 10.7, улучшена обработка больших ЦМР (>10 000 × 10 000 пикселей).
- При работе с высоким разрешением возможны ошибки нехватки памяти — рекомендуется использовать **scratch workspace** на быстром диске.
- Результат можно сразу стилизовать через *Symbology → Quantities → Graduated colors* по полю `Contour`.

#### Типичные настройки:
- **Топокарта 1:50 000**: интервал = 10 м, базовая = 0
- **Инженерные изыскания**: интервал = 1 м, базовая = 100 м

## 8. Ограничения и особенности

1. **Требование к проекции**: ЦМР **обязательно должна быть в метрической проекции**.
2. **Чувствительность к разрешению**: низкое разрешение сглаживает детали рельефа, высокое — создаёт избыточное количество мелких изолиний.
3. **NoData-значения**: вызывают разрывы в линиях; рекомендуется предварительно выполнить заполнение (Fill).
4. **Не работает с категориальными растрaми**: только с непрерывными числовыми данными.
5. **Производительность**: время выполнения растёт с увеличением размера ЦМР и уменьшением интервала.
