# Водосборный бассейн (Watershed)

## 1. Введение и теоретические основы

Водосборный бассейн (англ. *watershed*) — это операция гидрологического анализа рельефа, направленная на **выделение территории, с которой поверхностный сток воды собирается в заданную точку или линейный объект (например, водоток)**. С гидрологической точки зрения, водосборный бассейн ограничен **водоразделами** — линиями, разделяющими потоки, стекающие в разные реки или водоёмы.

Математически, watershed определяется как множество всех ячеек цифровой модели рельефа (ЦМР), для которых путь стока (согласно растрy направления стока) проходит через заданную **точку слияния (pour point)**. Алгоритм работает в обратном направлении от pour point, рекурсивно поднимаясь вверх по цепочке направлений стока до тех пор, пока не будут охвачены все вышестоящие ячейки.

В контексте геоинформационных систем выделение водосборных бассейнов служит ключевым инструментом для:
- оценки площади водосбора для гидрологических расчётов,
- моделирования распространения загрязнений,
- планирования мероприятий по охране водных ресурсов,
- анализа эрозионной активности и селевой опасности.

Методологически watershed относится к классу **гидрологических преобразований растровых поверхностей** и требует наличия **растрa направления стока**, полученного после последовательной обработки: *Fill Sinks → Flow Direction*.

## 2. Ключевые слова и семантические триггеры

водосборный бассейн, watershed, бассейн стока, pour point, водораздел, QGIS Watershed, ArcMap Watershed

## 3. Область применения

- **Гидрология**: расчёт площади водосбора для гидрологических станций.
- **Экология**: определение зон влияния на водные объекты для охраны.
- **Сельское хозяйство**: оценка стока удобрений и пестицидов в реки.
- **Градостроительство**: моделирование зон подтопления при ливнях.
- **Лесное хозяйство**: анализ селевой опасности в горных районах.
- **Управление ЧС**: прогнозирование путей распространения загрязнений.

## 4. Входные данные

- **Растр направления стока** (flow direction), полученный после *Fill Sinks → Flow Direction*.
- **Точки слияния (pour points)**: точечный слой с координатами, для которых требуется выделить бассейны.
- **Система координат**: проекция должна быть в **линейных единицах (метрах)**.
- **Опционально**: растр накопления потока для автоматического определения значимых водотоков.

> ⚠️ **Важно**: Точки слияния должны точно совпадать с ячейками растра направления стока. Рекомендуется использовать **Snap Pour Point** для привязки к ячейкам с максимальным накоплением.

## 5. Выходные данные

- Новый **полигональный векторный слой** (или растр), где каждый объект представляет водосборный бассейн.
- Атрибутивная таблица содержит:
  - `PourPtID` — идентификатор точки слияния,
  - `Area` — площадь бассейна (если рассчитана),
  - `OutletX`, `OutletY` — координаты устья.
- Возможность экспорта в shapefile, geodatabase или GeoJSON.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Растры → Анализ → Инструменты гидрологии → Водосборный бассейн...
- **Альтернатива**: использовать **GRASS r.water.outlet** через Processing Toolbox.
- **Параметры**:
  - Input flow direction layer: растр направления стока,
  - Pour points: точечный слой,
  - Output: путь к выходному файлу.
- **Особенности**: 
  - Поддерживает несколько точек слияния за один запуск,
  - Автоматически привязывает точки к ближайшей ячейке,
  - Результат можно сразу использовать для Zonal Statistics.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Watershed** входит в состав расширения **Spatial Analyst**, которое должно быть активировано (*Customize → Extensions → Spatial Analyst*).

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Spatial Analyst Tools → Hydrology → Watershed**.

#### Основные параметры:
- **Input raster or feature pour point data**: точечный слой или растр точек слияния.
- **Input flow direction raster**: растр направления стока.
- **Output raster**: путь к выходному растрy (можно конвертировать в полигоны через *Raster to Polygon*).
- **Pour point field**: поле с уникальными ID точек.

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 рекомендуется предварительно выполнить **Snap Pour Point** для повышения точности.
- Начиная с 10.7, улучшена обработка больших ЦМР (>10 000 × 10 000 пикселей).
- При работе с высоким разрешением возможны ошибки нехватки памяти — рекомендуется использовать **scratch workspace** на быстром диске.
- Результат — растр; для получения полигонов требуется дополнительный шаг: **Conversion Tools → From Raster → Raster to Polygon**.

#### Типичные сценарии:
- **Гидрологический расчёт**:  
  Pour points = станции.shp → Watershed → площадь водосбора для каждой станции.
- **Экологический мониторинг**:  
  Pour points = устья рек → Watershed → зоны влияния на водные объекты.

## 8. Ограничения и особенности

1. **Требует корректного Flow Direction**: без него результат будет фрагментированным или пустым.
2. **Чувствителен к положению pour point**: даже смещение на одну ячейку может изменить бассейн.
3. **Не учитывает подземный сток**: модель ограничена поверхностным стоком.
4. **Производительность**: время выполнения растёт с увеличением размера ЦМР и числа точек.
5. **Требует метрической проекции**: иначе площадь водосбора будет рассчитана неверно.
