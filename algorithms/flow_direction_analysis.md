# Направление стока (Flow Direction)

## 1. Введение и теоретические основы

Направление стока (англ. *flow direction*) — это фундаментальная операция гидрологического анализа рельефа, направленная на **определение направления движения поверхностных вод из каждой ячейки цифровой модели рельефа (ЦМР)**. Данная операция лежит в основе всех последующих гидрологических расчётов: накопления потока, построения речной сети, выделения водосборных бассейнов.

С гидрологической точки зрения, вода стекает от более высоких точек к более низким под действием силы тяжести. Алгоритмы flow direction моделируют этот процесс, присваивая каждой ячейке код направления — обычно по одной из двух схем:
- **D8 (Deterministic 8)**: вода стекает в одну из 8 соседних ячеек с наибольшим уклоном (Jenson & Domingue, 1988),
- **D∞ (D-infinity)**: вода распределяется между двумя соседними ячейками в пропорции, соответствующей форме склона (Tarboton, 1997).

В контексте геоинформационных систем направление стока служит обязательным этапом подготовки данных для:
- моделирования поверхностного стока,
- расчёта зон водосбора,
- оценки эрозионной активности,
- анализа путей распространения загрязнений.

Методологически flow direction относится к классу **гидрологических преобразований растровых поверхностей** и требует **гидрологически корректной ЦМР** (предварительно обработанной через *Fill Sinks*).

## 2. Ключевые слова и семантические триггеры

направление стока, flow direction, D8, D-infinity, гидрологический анализ, QGIS Flow Direction, ArcMap Flow Direction

## 3. Область применения

- **Гидрология**: построение речной сети и водосборных бассейнов.
- **Экология**: анализ путей миграции загрязнений в водные объекты.
- **Сельское хозяйство**: оценка эрозионной устойчивости склонов.
- **Градостроительство**: моделирование стока ливневых вод при проектировании.
- **Лесное хозяйство**: прогнозирование распространения паводковых вод.
- **Управление ЧС**: оценка зон подтопления при таянии снега или ливнях.

## 4. Входные данные

- **Цифровая модель рельефа (ЦМР)** в виде растрa (GeoTIFF, GRID, IMG), **предварительно обработанная через Fill Sinks**.
- **Система координат**: проекция должна быть в **линейных единицах (метрах)**.
- **Разрешение**: чем выше, тем точнее направление стока.
- **Отсутствие NoData-значений** в зоне интереса.

> ⚠️ **Важно**: Без предварительного заполнения впадин (fill sinks) направление стока будет **прерываться** в локальных минимумах, что сделает дальнейший анализ некорректным.

## 5. Выходные данные

- Новый растр того же разрешения и экстента, что и исходная ЦМР.
- Значения ячеек — **коды направлений**:
  - Для D8: целые числа от 1 до 128 (кодировка ESRI: 1=восток, 2=юго-восток, 4=юг и т.д.),
  - Для D∞: два значения на ячейку (направление и пропорция).
- Тип данных: обычно **int8** или **int16**.
- NoData-значения сохраняются в тех же местах, что и в исходном растре.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Растры → Анализ → Инструменты гидрологии → Направление стока...
- **Альтернатива**: использовать **GRASS r.watershed** или **SAGA Flow Accumulation (Top-Down)** через Processing Toolbox.
- **Параметры**:
  - Input layer: ЦМР (после Fill Sinks),
  - Output: путь к выходному файлу,
  - Algorithm: D8 (по умолчанию).
- **Особенности**: 
  - Поддерживает только D8 в стандартном инструменте,
  - Результат можно сразу использовать в **Flow Accumulation**,
  - Автоматически определяет единицы измерения CRS.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Flow Direction** входит в состав расширения **Spatial Analyst**, которое должно быть активировано (*Customize → Extensions → Spatial Analyst*).

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Spatial Analyst Tools → Hydrology → Flow Direction**.

#### Основные параметры:
- **Input surface raster**: ЦМР (после Fill).
- **Output raster**: путь к выходному файлу.
- **Force flow**: опция принудительного направления (используется редко).
- **Flow direction type**: 
  - *D8* (по умолчанию),
  - *DINF* (только в ArcGIS Pro; в ArcMap 10.4–10.8 — только D8).

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 используется только алгоритм D8.
- Начиная с 10.7, улучшена обработка больших ЦМР (>10 000 × 10 000 пикселей).
- При работе с высоким разрешением возможны ошибки нехватки памяти — рекомендуется использовать **scratch workspace** на быстром диске.
- Результат автоматически добавляется на карту и может быть использован в **Flow Accumulation**.

#### Типичные настройки:
- **Стандартный гидроанализ**: Input = dem_filled.tif → Output = flow_dir.tif → далее Flow Accumulation.

## 8. Ограничения и особенности

1. **Требует предварительного Fill Sinks**: без этого результат некорректен.
2. **D8 создаёт «решётчатый» сток**: вода движется только по 8 направлениям, что может искажать реальные пути.
3. **Не учитывает препятствия**: дороги, плотины, здания не учитываются (требуется модификация ЦМР).
4. **Производительность**: время выполнения растёт с увеличением размера ЦМР.
5. **Требует метрической проекции**: иначе уклон рассчитывается неверно.
