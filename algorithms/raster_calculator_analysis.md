# Растровый калькулятор (Raster Calculator)

## 1. Введение и теоретические основы

Растровый калькулятор (англ. *raster calculator*) — это фундаментальная операция растрового анализа, позволяющая выполнять **математические, логические и условные операции над одним или несколькими растровыми слоями** с помощью пользовательских выражений. Данная функция реализует принцип **картографической алгебры**, введённый Томлином (Tomlin, 1990), согласно которому пространственные данные могут быть обработаны как переменные в математических формулах.

С математической точки зрения, raster calculator применяет **точечную (пиксельную) операцию**:  
\[
R_{\text{out}}(x, y) = f(R_1(x, y), R_2(x, y), ..., R_n(x, y))
\]  
где \( f \) — произвольное выражение, включающее арифметические операторы (`+`, `-`, `*`, `/`), функции (`sin`, `log`, `sqrt`), логические условия (`>`, `<`, `==`) и условные конструкции (`Con`, `SetNull`).

В контексте геоинформационных систем растровый калькулятор служит универсальным инструментом для:
- создания индексов (например, NDVI, NDBI),
- нормализации данных,
- комбинирования факторов в моделях пригодности,
- маскирования (например, удаление облачности по порогу),
- преобразования единиц измерения (например, метры → футы).

Методологически raster calculator относится к классу **локальных (точечных) операций над растровыми данными**, где значение выходной ячейки зависит только от значений входных ячеек в той же позиции.

## 2. Ключевые слова и семантические триггеры

растровый калькулятор, raster calculator, картографическая алгебра, математические операции над растром, QGIS Raster Calculator, ArcMap Raster Calculator, калькулятор растра

## 3. Область применения

- **Дистанционное зондирование**: расчёт спектральных индексов (NDVI, EVI, SAVI).
- **Оценка пригодности территорий**: взвешенная сумма нормализованных факторов.
- **Экологический мониторинг**: выделение водных объектов по порогу отражательной способности.
- **Гидрология**: преобразование высоты в потенциальную энергию.
- **Управление ЧС**: создание бинарной маски затопления (если уровень воды > 5 м → 1, иначе 0).
- **Сельское хозяйство**: оценка стресса растений по комбинации индексов.

## 4. Входные данные

- **Один или несколько растровых слоёв** (GeoTIFF, GRID, IMG) с числовыми значениями.
- **Математическое выражение**, написанное на языке, поддерживаемом ГИС:
  - В QGIS: синтаксис на основе Python/NumPy,
  - В ArcMap: синтаксис на основе Map Algebra.
- **Общая система координат и разрешение**: все растрy должны быть приведены к одному экстенту и разрешению (автоматически или вручную).

> ⚠️ **Важно**: Если растрy имеют разный размер или проекцию, результат может быть некорректным. Рекомендуется предварительно выполнить **Resample** и **Project Raster**.

## 5. Выходные данные

- Новый растровый слой того же разрешения и экстента, что и входные данные.
- Значения ячеек — результат вычисления выражения.
- Тип данных: определяется автоматически (float32 для дробных, int16 для целых) или задаётся вручную.
- NoData-значения обрабатываются в соответствии с логикой выражения.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Растры → Анализ → Калькулятор растра...
- **Параметры**:
  - Input layers: список доступных растрoв,
  - Expression: поле для ввода формулы (с подсветкой синтаксиса),
  - Output layer: путь к выходному файлу,
  - Output extent / CRS: можно задать вручную.
- **Особенности**: 
  - Поддерживает условные операторы через `if(condition, true_value, false_value)`,
  - Можно использовать константы и математические функции (`log`, `exp`, `sqrt`),
  - Автоматически обрабатывает NoData.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Raster Calculator** входит в состав расширения **Spatial Analyst**, которое должно быть активировано (*Customize → Extensions → Spatial Analyst*).

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Spatial Analyst Tools → Map Algebra → Raster Calculator**.

#### Основные параметры:
- **Expression**: поле для ввода формулы в синтаксисе Map Algebra:
  - Растрy обозначаются как `"layer_name@1"` (для многополосных),
  - Условные операторы: `Con(condition, true_value, false_value)`,
  - Функции: `Sin`, `Log`, `Sqrt`, `Int`, `Float`.
- **Output raster**: путь к выходному файлу.

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 интерфейс менее гибкий — нет автодополнения.
- Начиная с 10.7, улучшена обработка больших растрoв и сложных выражений.
- При работе с высоким разрешением возможны ошибки нехватки памяти — рекомендуется использовать **scratch workspace** на быстром диске.
- Результат можно сразу использовать в других инструментах Spatial Analyst.

#### Типичные выражения:
- **NDVI**:  
  `(NIR - Red) / (NIR + Red)`  
  → в ArcMap: `("band5" - "band4") / ("band5" + "band4")`
- **Бинарная маска**:  
  → в QGIS: `if("slope" > 15, 0, 1)`  
  → в ArcMap: `Con("slope" > 15, 0, 1)`

## 8. Ограничения и особенности

1. **Требование к типу данных**: работает только с **численными растрaми**.
2. **Чувствительность к NoData**: если хотя бы один входной растр содержит NoData в ячейке, результат будет NoData (если не обработано явно).
3. **Производительность**: сложные выражения с большим числом растрoв могут выполняться долго.
4. **Ошибки синтаксиса**: неправильная скобка или имя слоя приводят к ошибке без подробного объяснения.
5. **Не сохраняет историю**: каждое выражение нужно вводить заново (если не сохранено в модели).
