# Евклидово расстояние (Euclidean Distance)

## 1. Введение и теоретические основы

Евклидово расстояние (англ. *Euclidean Distance*) — это фундаментальная операция растрового анализа, направленная на **расчёт прямолинейного (кратчайшего) расстояния от каждой ячейки растрa до ближайшего объекта в исходном слое**. Данная операция реализует метрику евклидова пространства:

\[
D(x, y) = \sqrt{(x - x_0)^2 + (y - y_0)^2}
\]

где \( (x_0, y_0) \) — координаты ближайшей точки исходного объекта, а \( (x, y) \) — координаты текущей ячейки.

В контексте геоинформационных систем Euclidean Distance служит базовым инструментом для:
- оценки доступности (например, расстояния до ближайшей школы),
- зонирования территорий по критерию удалённости,
- подготовки входных данных для моделей пригодности,
- анализа рассеивания видов в экологии.

Методологически данная операция относится к классу **расстоянных преобразований (distance transforms)** и является частным случаем **функции стоимости**, где стоимость перемещения постоянна во всех направлениях.

## 2. Ключевые слова и семантические триггеры

евклидово расстояние, euclidean distance, расстояние до объекта, зона доступности, QGIS Euclidean Distance, ArcMap Euclidean Distance

## 3. Область применения

- **Градостроительство**: расчёт расстояния до ближайшей школы, больницы или парка.
- **Экология**: оценка удалённости от источников загрязнения или мест обитания видов.
- **Логистика**: определение зон обслуживания складов или пунктов выдачи.
- **Сельское хозяйство**: анализ удалённости полей от центрального пункта техобслуживания.
- **Управление ЧС**: расчёт времени эвакуации до ближайшего укрытия.
- **Рекреация**: построение карт «удалённости от цивилизации» для туристических маршрутов.

## 4. Входные данные

- **Исходный слой**: 
  - либо **точечный**, 
  - либо **линейный**, 
  - либо **полигональный** векторный слой,
  - либо **бинарный растр** (1 — объект, 0 — фон).
- **Максимальное расстояние** (необязательно): ограничение зоны расчёта (например, 5000 м).
- **Система координат**: проекция должна быть в **линейных единицах (метрах)**.

> ⚠️ **Важно**: Если используется географическая система (WGS84), результат будет в **градусах**, что не имеет практического смысла. Обязательна метрическая проекция.

## 5. Выходные данные

- Новый растр того же разрешения и экстента, что и область анализа.
- Значения ячеек — расстояние до ближайшего объекта в **единицах CRS** (обычно метрах).
- Тип данных: обычно **float32**.
- Ячейки, совпадающие с исходными объектами, получают значение **0**.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Растры → Анализ → Инструменты proximity (растровые расстояния) → Расстояние до ближайшего объекта...
- **Параметры**:
  - Input layer: исходный векторный слой или растр,
  - Target raster layer: опционально — растр, задающий область анализа,
  - Maximum distance: максимальное расстояние (в единицах CRS),
  - Output raster: путь к выходному файлу.
- **Особенности**: 
  - Использует GDAL-реализацию,
  - Автоматически определяет единицы измерения CRS,
  - Поддерживает все типы геометрии.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Euclidean Distance** входит в состав расширения **Spatial Analyst**, которое должно быть активировано (*Customize → Extensions → Spatial Analyst*).

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Spatial Analyst Tools → Distance → Euclidean Distance**.

#### Основные параметры:
- **Input raster or feature source data**: исходный слой (вектор или растр).
- **Maximum distance**: максимальное расстояние (в единицах CRS).
- **Output cell size**: разрешение выходного растрa (по умолчанию — как у входного).
- **Output distance raster**: путь к выходному файлу.

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 инструмент может работать медленно с большим числом объектов (>10 000).
- Начиная с 10.7, улучшена обработка больших наборов данных.
- При работе с высоким разрешением возможны ошибки нехватки памяти — рекомендуется использовать **scratch workspace** на быстром диске.
- Результат можно сразу использовать в **Reclassify** (например, 0–500 м → «высокая доступность»).

#### Типичные сценарии:
- **Доступность школ**:  
  Исходный слой = школы.shp → Расстояние до ближайшей школы.
- **Зона шума**:  
  Исходный слой = дороги.shp → Расстояние до ближайшей дороги → переклассификация в уровни шума.

## 8. Ограничения и особенности

1. **Требование к проекции**: обязательна **метрическая проекция**.
2. **Прямолинейность**: не учитывает препятствия (здания, реки) — для этого используется **Cost Distance**.
3. **Производительность**: время выполнения растёт с увеличением области анализа и числа исходных объектов.
4. **Разрешение**: низкое разрешение снижает точность расчёта расстояний.
5. **Не подходит для глобальных расчётов**: на больших территориях требуется проекция, минимизирующая искажения расстояний (например, Equidistant Conic).
