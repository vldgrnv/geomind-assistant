# Зональная статистика (Zonal Statistics)

## 1. Введение и теоретические основы

Зональная статистика (англ. *zonal statistics*) — это фундаментальная операция растрового анализа, направленная на **вычисление статистических показателей значений одного растра (значения) в пределах зон, определённых другим растром или векторным слоем (зоны)**. Данная операция позволяет агрегировать пространственные данные по территориальным единицам, таким как административные районы, почвенные типы, ландшафтные классы или любые другие полигональные/растровые зоны.

С математической точки зрения, для каждой зоны \( Z_i \) вычисляется набор статистик над множеством ячеек \( R_j \), пересекающихся с этой зоной:
\[
\text{Stat}(Z_i) = f(\{R_j \mid R_j \cap Z_i \neq \emptyset\})
\]
где \( f \) — статистическая функция: среднее, сумма, минимум, максимум, стандартное отклонение и др.

В контексте геоинформационных систем зональная статистика служит ключевым инструментом для:
- агрегации данных дистанционного зондирования по административным границам,
- оценки средней высоты или уклона в пределах кадастровых участков,
- расчёта общей площади лесов в каждом районе (через переклассифицированный растр),
- анализа среднего уровня загрязнения воздуха по жилым кварталам.

Методологически zonal statistics относится к классу **зональных операций над растровыми данными**, где результат зависит от пространственного совпадения двух слоёв.

## 2. Ключевые слова и семантические триггеры

зоновая статистика, zonal statistics, агрегация по зонам, статистика по районам, QGIS Zonal Statistics, ArcMap Zonal Statistics

## 3. Область применения

- **Сельскохозяйственная статистика**: расчёт среднего NDVI по растительным округам.
- **Экологический мониторинг**: оценка средней высоты лесных массивов в заказниках.
- **Градостроительство**: расчёт общей площади застройки в каждом микрорайоне.
- **Сельское хозяйство**: определение среднего уклона полей по кадастровым участкам.
- **Управление ЧС**: суммарная площадь затопленных территорий по муниципалитетам.
- **Климатология**: средняя температура по климатическим зонам.

## 4. Входные данные

- **Слой зон**: 
  - либо **полигональный векторный слой** (районы, участки),
  - либо **растровый слой с категориальными значениями** (почвы, землепользование).
- **Слой значений**: **численный растр** (высота, температура, плотность, NDVI и т.д.).
- **Система координат**: оба слоя должны быть в одной проекции (рекомендуется метрическая).
- **Разрешение**: разрешение растрa значений должно быть не грубее, чем размер зон.

> ⚠️ **Важно**: Если зона частично покрывает ячейку растрa, используется **долевое участие** (по умолчанию — центр ячейки должен попадать в зону).

## 5. Выходные данные

- **Для векторных зон**: обогащённая атрибутивная таблица с новыми полями:
  - `MEAN` — среднее значение,
  - `SUM` — сумма,
  - `MIN`, `MAX` — минимум и максимум,
  - `STD` — стандартное отклонение,
  - `COUNT` — число ячеек.
- **Для растровых зон**: новый растр, где каждая зона заполнена выбранным статистическим значением.
- Тип данных: зависит от выбранной статистики (float для среднего, int для суммы и т.д.).

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Растры → Анализ → Инструменты зоновой статистики → Зоновая статистика...
- **Параметры**:
  - Input raster layer: растр значений,
  - Vector layer containing zones: полигональный слой зон,
  - Statistics to calculate: выбор нужных статистик,
  - Output column prefix: префикс для новых полей (например, `ndvi_`).
- **Особенности**: 
  - Результат записывается прямо в атрибутивную таблицу векторного слоя,
  - Поддерживает все основные статистики,
  - Можно выбрать, учитывать ли NoData.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Zonal Statistics** входит в состав расширения **Spatial Analyst**, которое должно быть активировано (*Customize → Extensions → Spatial Analyst*).

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Spatial Analyst Tools → Zonal → Zonal Statistics** (или **Zonal Statistics as Table**).

#### Основные параметры:
- **Input raster or feature zone data**: слой зон (вектор или растр).
- **Zone field**: поле, определяющее уникальные зоны (например, `district_id`).
- **Input value raster**: растр со значениями.
- **Output raster/table**: 
  - *Zonal Statistics* → создаёт растр,
  - *Zonal Statistics as Table* → создаёт таблицу (чаще используется).
- **Statistics type**: выбор статистики (MEAN, SUM, MIN, MAX, STD и др.).

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 инструмент может работать медленно с большим числом зон (>10 000).
- Начиная с 10.7, улучшена обработка NoData и дробных значений.
- При работе с векторными зонами рекомендуется использовать **Zonal Statistics as Table**, а затем присоединить таблицу через **Join**.
- Результат можно сразу использовать в **Chart** или **Report**.

#### Типичные сценарии:
- **Агрегация NDVI по районам**:  
  Зоны = районы.shp, Значения = ndvi.tif → Таблица со средним NDVI по районам.
- **Площадь лесов**:  
  Зоны = районы.shp, Значения = land_cover_reclass.tif (лес=1, остальное=0) → Сумма = площадь леса в ячейках.

## 8. Ограничения и особенности

1. **Требование к проекции**: оба слоя **должны быть в одной системе координат**.
2. **Чувствительность к разрешению**: если растр значений слишком грубый, статистика будет неточной.
3. **Обработка частичного перекрытия**: по умолчанию учитывается только центр ячейки; для точного расчёта требуется интерполяция.
4. **Производительность**: время выполнения растёт с увеличением числа зон и размера растрa.
5. **NoData-значения**: могут исказить статистику, если не обработаны явно.
