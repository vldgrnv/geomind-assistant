# Исправление геометрии (Repair Geometry)

## 1. Введение и теоретические основы

Исправление геометрии (англ. *repair geometry*) — это фундаментальная операция векторной обработки данных, направленная на **выявление и устранение топологических ошибок в геометрии объектов**, возникающих в результате неточной оцифровки, преобразования форматов, импорта из внешних источников или программных сбоев. К типичным ошибкам относятся: самопересечения полигонов, незамкнутые кольца, дублирующиеся вершины, некорректные ориентации колец, щели между смежными полигонами и другие нарушения пространственной целостности.

С геометрической точки зрения, корректный объект должен удовлетворять определённым аксиомам:
- Полигон должен быть **замкнутым** и не иметь **самопересечений**,
- Внешнее кольцо должно быть ориентировано **по часовой стрелке**, внутренние (острова) — **против**,
- Линия не должна содержать **повторяющихся последовательных вершин**,
- Точка должна иметь **одну пару координат**.

В контексте геоинформационных систем данная операция служит **обязательным этапом подготовки данных** перед выполнением overlay-анализа, топологического контроля, публикации карт или передачи данных в другие системы. Без исправления геометрии результаты анализа могут быть искажены, а программное обеспечение — выдавать ошибки или аварийно завершать работу.

Методологически repair geometry относится к классу **операций по контролю качества пространственных данных (Spatial Data Quality Control)** и реализует принцип **геометрической валидации**.

## 2. Ключевые слова и семантические триггеры

исправление геометрии, repair geometry, очистка данных, топологические ошибки, самопересечения, QGIS Fix Geometries, ArcMap Repair Geometry

## 3. Область применения

- **Подготовка данных к анализу**: устранение ошибок перед выполнением clip, intersect, union.
- **Импорт данных**: очистка после конвертации из CAD, KML, CSV.
- **Публикация карт**: обеспечение корректности для веб-картографии.
- **Обмен данными**: приведение к стандарту при передаче партнёрам.
- **Архивирование**: сохранение данных в валидном состоянии.
- **Подготовка к печати**: исключение артефактов на бумажных картах.

## 4. Входные данные

- **Векторный слой** любого типа геометрии (точки, линии, полигоны).
- **Система координат**: любая (операция не зависит от проекции).
- **Тип ошибок**: могут включать самопересечения, щели, дубли вершин, некорректные кольца.

> ⚠️ **Важно**: Операция **не исправляет атрибутивные ошибки** (дубли строк, пустые поля) — только геометрию.

## 5. Выходные данные

- Новый векторный слой того же типа геометрии.
- Все объекты приведены к **топологически корректному состоянию**.
- Атрибутивная таблица сохраняется без изменений.
- Объекты, которые невозможно исправить, могут быть удалены или помещены в отдельный файл (в зависимости от настроек).

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Вектор → Инструменты геометрии → Исправить геометрии...
- **Параметры**:
  - Input layer: исходный слой,
  - Output: путь к выходному файлу.
- **Особенности**: 
  - Использует GEOS-библиотеку для валидации,
  - Автоматически разбивает самопересекающиеся полигоны на допустимые части,
  - Удаляет дублирующиеся вершины и замыкает разомкнутые кольца,
  - Работает со всеми типами геометрии.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Repair Geometry** входит в состав модуля **Data Management Tools**.

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Data Management Tools → Features → Repair Geometry**.

#### Основные параметры:
- **Input Features**: исходный векторный слой.
- **Delete features with null geometry**: удалять ли объекты без геометрии (по умолчанию — да).
- **Extent / XY Tolerance**: можно задать допуск для слияния близких вершин.

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 инструмент может работать медленно с большими наборами данных (>50 000 объектов).
- Начиная с 10.7, улучшена обработка сложных самопересечений.
- При работе с shapefile возможна потеря точности — рекомендуется использовать **File Geodatabase**.
- Инструмент **не создаёт нового слоя**, а **изменяет исходный** (рекомендуется делать резервную копию).

#### Типичные сценарии:
- **Подготовка к анализу**:  
  Input = участки_сырые.shp → Output = участки_очищенные.shp → далее Clip/Intersect.
- **Импорт из KML**:  
  После импорта KML часто возникают самопересечения → Repair Geometry решает проблему.

## 8. Ограничения и особенности

1. **Не восстанавливает смысловые ошибки**: если полигон нарисован неправильно (например, вместо круга — звезда), это не будет исправлено.
2. **Может изменить количество объектов**: один самопересекающийся полигон может стать двумя.
3. **Производительность**: время выполнения растёт с увеличением числа объектов и сложности геометрии.
4. **ArcMap-особенность**: работает **in-place** (изменяет исходный слой), что требует осторожности.
5. **Не гарантирует топологическую согласованность между слоями**: например, щели между соседними полигонами могут остаться.
