# Анализ кластеров и выбросов (Cluster and Outlier Analysis, Anselin Local Moran’s I)

## 1. Введение и теоретические основы

Анализ кластеров и выбросов (англ. *cluster and outlier analysis*) — это метод локальной пространственной статистики, направленный на **выявление статистически значимых кластеров схожих значений («горячих» и «холодных» точек) и пространственных выбросов (аномалий)** в распределении количественного признака по территории. Метод основан на **локальном индексе Морана (Local Moran’s I)**, предложенном Лукасом Анселеном (Anselin, 1995), который оценивает автокорреляцию между каждым объектом и его соседями.

Формула локального индекса Морана для объекта \( i \):
\[
I_i = \frac{(x_i - \bar{x})}{S^2} \sum_{j=1}^{n} w_{ij} (x_j - \bar{x})
\]
где:
- \( x_i, x_j \) — значения признака в объектах \( i \) и \( j \),
- \( \bar{x} \) — среднее значение,
- \( S^2 \) — дисперсия,
- \( w_{ij} \) — пространственный вес (обычно 1, если \( j \) в радиусе от \( i \)).

Результат интерпретируется через **четыре типа пространственных ассоциаций**:
- **HH (High-High)**: высокое значение окружено высокими → «горячая точка»,
- **LL (Low-Low)**: низкое значение окружено низкими → «холодная точка»,
- **HL (High-Low)**: высокое значение среди низких → положительный выброс,
- **LH (Low-High)**: низкое значение среди высоких → отрицательный выброс.

В отличие от глобального Moran’s I, который даёт один показатель для всего набора, Local Moran’s I позволяет **локализовать** зоны кластеризации и аномалии.

В контексте геоинформационных систем данный анализ служит ключевым инструментом для:
- выявления неоднородностей в социально-экономических данных,
- обнаружения аномальных экологических или криминальных ситуаций,
- поддержки принятия решений на основе локальных паттернов.

Методологически он относится к классу **локальных индикаторов пространственной автокорреляции (LISA)**.

## 3. Область применения

- **Социальная география**: выявление районов бедности среди благополучных (LH) или богатства среди бедных (HL).
- **Криминология**: обнаружение изолированных «островков» преступности (HL) или безопасных зон в криминальных районах (LH).
- **Экология**: поиск аномально чистых участков в зоне загрязнения (LH) или наоборот.
- **Экономика**: анализ локальных дисбалансов (например, высокая зарплата в регионе с низкими доходами).
- **Градостроительство**: выявление «белых пятен» в застройке или аномальных зон рекреации.
- **Здравоохранение**: обнаружение очагов заболеваний, не соответствующих общему фону.

## 4. Входные данные

- **Векторный слой**: точечный или полигональный.
- **Атрибутивное поле**: числовое поле с анализируемым признаком (например, `income`, `crime_rate`).
- **Матрица пространственных весов**: задаётся радиусом поиска или топологическим соседством.
- **Система координат**: желательно метрическая (для корректного задания радиуса в метрах).

> ⚠️ **Важно**: Поле не должно содержать **слишком много одинаковых значений**, так как это снижает чувствительность анализа.

## 5. Выходные данные

- Новый векторный слой с теми же геометриями.
- Атрибутивная таблица содержит поля:
  - `Local_I` — значение локального индекса Морана,
  - `PValue` — p-значение,
  - `COType` — тип ассоциации: `HH`, `LL`, `HL`, `LH`, `NS` (Not Significant).
- Возможность визуализации через цветовую шкалу:
  - **Красный** — HH,
  - **Синий** — LL,
  - **Розовый** — HL,
  - **Светло-синий** — LH,
  - **Серый** — NS.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Обработка → Инструментарий анализа → Local Moran’s I...
- **Требуется плагин**: **PySAL** (встроен в Processing Toolbox).
- **Параметры**:
  - Input layer: исходный слой,
  - Input field: атрибутивное поле,
  - Distance band: радиус анализа (в единицах CRS),
  - Output: путь к выходному файлу.
- **Особенности**: 
  - Поддерживает только точечные данные (для полигонов — предварительно центроиды),
  - Использует PySAL для расчётов,
  - Результат можно сразу стилизовать по полю `COType`.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Cluster and Outlier Analysis (Anselin Local Moran’s I)** входит в состав расширения **Spatial Statistics Tools**, доступного через **ArcToolbox**.

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Spatial Statistics Tools → Mapping Clusters → Cluster and Outlier Analysis (Anselin Local Moran’s I)**.

#### Основные параметры:
- **Input Feature Class**: исходный слой.
- **Input Field**: атрибутивное поле.
- **Output Feature Class**: путь к выходному файлу.
- **Conceptualization of Spatial Relationships**: 
  - *INVERSE_DISTANCE*,
  - *FIXED_DISTANCE_BAND*,
  - *CONTIGUITY_EDGES_ONLY* (для полигонов).
- **Distance Band**: радиус анализа (автоматически рассчитывается, но можно задать вручную).

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 интерфейс менее гибкий — нет предварительного просмотра.
- Начиная с 10.7, улучшена обработка больших наборов данных (>10 000 объектов).
- При работе с File Geodatabase результат более стабилен.
- Инструмент **автоматически определяет оптимальный радиус**, если он не задан.

#### Типичные сценарии:
- **Социальный анализ**:  
  Слой = районы.shp, Поле = `median_income` → выявление HH (богатые районы) и LH (бедный район среди богатых).
- **Криминология**:  
  Слой = преступления.shp, Поле = `count` → HL (всплеск преступности в спокойном районе).

## 8. Ограничения и особенности

1. **Требование к данным**: необходимо достаточное число объектов (>30) для статистической значимости.
2. **Чувствительность к радиусу**: выбор матрицы весов критичен для результата.
3. **Не работает с категориальными данными**: требуется числовой атрибут.
4. **Производительность**: время выполнения растёт квадратично с числом объектов.
5. **Интерпретация**: наличие кластера/выброса ≠ причинно-следственная связь — требуется дополнительный анализ.
