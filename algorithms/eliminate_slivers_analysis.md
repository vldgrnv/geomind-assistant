# Удаление щелей (Eliminate Slivers)

## 1. Введение и теоретические основы

Удаление щелей (англ. *eliminate slivers*) — это операция векторной обработки данных, направленная на **устранение мелких, топологически некорректных или нежелательных полигонов**, возникающих в результате overlay-анализа (например, при выполнении Intersect, Union, Identity). Такие объекты, называемые «щелями» (slivers) или «осколками», обычно имеют:
- очень малую площадь,
- вытянутую форму,
- артефактную геометрию (тонкие полосы между границами),
- отсутствие семантического смысла.

С геометрической точки зрения, slivers появляются из-за **несовершенного совпадения границ** исходных слоёв — даже при высокой точности оцифровки неизбежны микросмещения вершин, которые при overlay-анализе порождают узкие полигоны площадью от нескольких квадратных метров до долей квадратного миллиметра.

В контексте геоинформационных систем данная операция служит **обязательным этапом постобработки** после overlay-анализа и направлена на:
- повышение картографического качества,
- устранение артефактов перед публикацией,
- подготовку данных для последующего анализа (например, Zonal Statistics),
- обеспечение соответствия нормативным требованиям к пространственным данным.

Методологически eliminate slivers относится к классу **операций по очистке и генерализации векторных данных** и реализует принцип **топологической целостности**.

## 2. Ключевые слова и семантические триггеры

удаление щелей, eliminate slivers, очистка overlay, sliver polygons, QGIS Eliminate, ArcMap Eliminate

## 3. Область применения

- **Постобработка после Union/Intersect**: устранение артефактов между смежными районами.
- **Кадастр**: удаление микрополос между участками, возникших при межевании.
- **Градостроительство**: очистка зонирования после наложения функциональных зон.
- **Экология**: устранение шумовых полигонов в картах растительности.
- **Подготовка к печати**: исключение визуальных артефактов на бумажных картах.
- **Агрегация данных**: упрощение результата перед статистическим анализом.

## 4. Входные данные

- **Полигональный векторный слой**, содержащий нежелательные мелкие полигоны.
- **Критерий отбора щелей**: обычно площадь (< 100 м²), но может быть и периметр/площадь (compactness).
- **Система координат**: желательно метрическая (для корректного расчёта площади).

> ⚠️ **Важно**: Слой должен быть **топологически корректным** (без самопересечений). Рекомендуется предварительно выполнить **Repair Geometry**.

## 5. Выходные данные

- Новый полигональный слой, в котором щели **удалены за счёт присоединения к соседним полигонам**.
- Атрибутивная таблица сохраняет поля **соседнего полигона**, к которому была присоединена щель.
- Общее число объектов уменьшается.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Вектор → Инструменты геообработки → Удалить выделенные объекты...
- **Альтернатива**: использовать **Select by Expression** → `area($geometry) < 100` → затем **Eliminate Selected Polygons** (через Processing Toolbox).
- **Параметры**:
  - Input layer: слой с щелями,
  - Selection expression: условие отбора (например, `"area" < 100`),
  - Merge selection with: соседний полигон с наибольшей общей границей.
- **Особенности**: 
  - Поддерживает выбор по площади, периметру или пользовательскому выражению,
  - Автоматически определяет лучшего соседа по длине общей границы,
  - Результат сохраняется как новый слой.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Eliminate** входит в состав модуля **Data Management Tools**.

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Data Management Tools → Generalization → Eliminate**.

#### Основные параметры:
- **Input Features**: полигональный слой со щелями.
- **Output Feature Class**: путь к выходному файлу.
- **Selection**: предварительно выделенные объекты (щели).
- **Merge adjacent polygons**: 
  - *LENGTH* — присоединять к соседу с наибольшей общей границей,
  - *AREA* — присоединять к соседу с наибольшей площадью.

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 требуется **предварительное выделение** щелей (например, через Select By Attribute: `"Shape_Area" < 100`).
- Начиная с 10.7, улучшена обработка сложных случаев с несколькими соседями.
- При работе с File Geodatabase результат более стабилен, чем с shapefile.
- Инструмент **сохраняет атрибуты соседнего полигона**, а не удаляемой щели.

#### Типичные сценарии:
- **После Union районов**:  
  Выделить полигоны с площадью < 50 м² → Eliminate → чистая карта районов.
- **После Intersect лесов и заказников**:  
  Удалить slivers площадью < 10 м² → корректная статистика по площади.

## 8. Ограничения и особенности

1. **Требует предварительного отбора**: в ArcMap нужно вручную выделять щели.
2. **Потеря атрибутов**: атрибуты удаляемой щели теряются — сохраняются только атрибуты соседа.
3. **Чувствительность к критерию**: слишком высокий порог площади может удалить значимые объекты.
4. **Не работает с изолированными щелями**: если щель не имеет соседей, она не будет удалена.
5. **Производительность**: время выполнения растёт с увеличением числа объектов.
