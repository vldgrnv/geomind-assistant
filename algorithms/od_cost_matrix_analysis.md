# Матрица корреспонденций (OD Cost Matrix)

## 1. Введение и теоретические основы

Матрица корреспонденций (англ. *Origin-Destination Cost Matrix*, OD Matrix) — это операция сетевого анализа, направленная на **расчёт стоимости (расстояния, времени, топлива) перемещения от каждого объекта в наборе «источников» (Origins) к каждому объекту в наборе «назначений» (Destinations)**. Результат представляет собой таблицу, где строки соответствуют источникам, столбцы — назначениям, а ячейки содержат минимальную стоимость пути между ними.

С математической точки зрения, OD-матрица является результатом решения множества задач кратчайшего пути:
\[
M_{ij} = \min_{P \in \mathcal{P}(O_i, D_j)} \sum_{e \in P} w(e)
\]
где:
- \( O_i \) — i-й источник,
- \( D_j \) — j-е назначение,
- \( w(e) \) — вес ребра (стоимость).

В контексте геоинформационных систем OD-матрица служит основой для:
- логистического планирования (распределение заказов по курьерам),
- оценки доступности (время до ближайшей школы, больницы),
- моделирования пассажиропотоков,
- анализа конкурентной среды (расстояние до ближайших торговых точек).

Методологически OD Cost Matrix относится к классу **сетевых (network-based) операций** и требует предварительной **топологической подготовки данных**.

## 2. Ключевые слова и семантические триггеры

матрица корреспонденций, OD matrix, origin-destination, матрица расстояний, QGIS OD Matrix, ArcMap Network Analyst

## 3. Область применения

- **Логистика**: расчёт времени доставки от складов к клиентам.
- **Градостроительство**: оценка времени в пути от жилых домов до социальных объектов.
- **Транспортное планирование**: моделирование пассажиропотоков между станциями метро.
- **Розничная торговля**: анализ конкуренции — расстояние до ближайших магазинов.
- **Здравоохранение**: оптимизация размещения скорой помощи по времени до пациентов.
- **Экология**: оценка миграционных потоков между местами обитания.

## 4. Входные данные

- **Сетевой слой**: линейный векторный слой (дороги, улицы), **топологически корректный**.
- **Атрибут стоимости**: числовой атрибут (например, `time_min`, `length`).
- **Слой источников (Origins)**: точечный слой (склады, дома, остановки).
- **Слой назначений (Destinations)**: точечный слой (клиенты, школы, магазины).
- **Ограничение по стоимости**: максимальное время/расстояние (опционально).

> ⚠️ **Важно**: Точки должны быть **привязаны к сети** (snap to network). Иначе расстояние будет рассчитано некорректно.

## 5. Выходные данные

- **Таблица (CSV, DBF, geodatabase table)** с полями:
  - `OriginID` — идентификатор источника,
  - `DestinationID` — идентификатор назначения,
  - `Total_Cost` — минимальная стоимость пути,
  - `Time`, `Distance` — дополнительные атрибуты (если заданы).
- Возможность экспорта в Excel, базы данных или GIS-проекты.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Анализ сети → Матрица расстояний (OD)...
- **Параметры**:
  - Vector layer representing network: слой дорог,
  - Start points (origins): слой источников,
  - End points (destinations): слой назначений,
  - Optimization attribute: атрибут стоимости (например, `time_min`),
  - Use direction: учёт одностороннего движения.
- **Особенности**: 
  - Не требует предварительного построения топологии,
  - Поддерживает привязку точек к ближайшему узлу сети,
  - Результат — таблица, которую можно сразу анализировать.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **OD Cost Matrix** доступен через расширение **Network Analyst**, которое должно быть активировано (*Customize → Extensions → Network Analyst*).

#### Этапы работы:
1. **Создание сетевого набора данных (Network Dataset)** (как в Shortest Path).
2. **Анализ OD-матрицы**:
   - Открыть Network Analyst → New OD Cost Matrix,
   - Добавить Origins и Destinations,
   - Указать Impedance (например, `Time`),
   - Задать Cutoff (максимальное время),
   - Нажать Solve.

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 интерфейс менее интуитивен.
- Начиная с 10.7, улучшена производительность при работе с большими наборами (>1000 × 1000).
- Требуется **File Geodatabase** для создания Network Dataset.
- Поддерживает **ограничение по количеству назначений** (например, найти 5 ближайших школ).

#### Типичные сценарии:
- **Доступность школ**:  
  Origins = дома.shp, Destinations = школы.shp → Время от каждого дома до каждой школы.
- **Логистика**:  
  Origins = склады.shp, Destinations = клиенты.shp → Время доставки.

## 8. Ограничения и особенности

1. **Требование к топологии**: линии должны быть корректно соединены в узлах.
2. **Производительность**: время расчёта растёт квадратично с увеличением числа точек (N × M).
3. **Не строит маршруты**: OD-матрица даёт только стоимость, но не геометрию пути (для этого нужен Shortest Path).
4. **Привязка точек**: если точки не попадают точно на сеть, используется автоматическая привязка (snap tolerance).
5. **ArcMap-зависимость**: Network Analyst недоступен в базовых лицензиях (только Standard/Advanced).
