# Ядерная плотность (Kernel Density)

## 1. Введение и теоретические основы

Ядерная плотность (англ. *kernel density*) — это метод пространственного анализа, направленный на **оценку интенсивности распределения точечных явлений** путём сглаживания их расположения с использованием функции ядра. В отличие от простого подсчёта количества точек в фиксированных ячейках (например, через *Point Density*), kernel density учитывает **расстояние до каждой точки**, придавая больший вес ближайшим событиям и постепенно снижая влияние с удалением.

Математически, плотность в точке \( (x, y) \) вычисляется как:
\[
\hat{f}(x, y) = \frac{1}{n h^2} \sum_{i=1}^{n} K\left( \frac{\| (x, y) - (x_i, y_i) \|}{h} \right)
\]
где:
- \( n \) — общее число точек,
- \( h \) — радиус поиска (bandwidth),
- \( K \) — функция ядра (обычно квадратичное или гауссово).

Результатом является **непрерывный растр**, где высокие значения соответствуют зонам концентрации точек («горячие зоны»), а низкие — зонам редкости. Это позволяет визуализировать **пространственные паттерны** даже при небольшом числе событий.

В контексте геоинформационных систем kernel density служит ключевым инструментом для:
- картографирования преступности,
- анализа распространения заболеваний,
- оценки плотности населения или транспортных потоков,
- моделирования среды обитания видов.

Методологически данный анализ относится к классу **непараметрических методов оценки плотности распределения** и требует наличия **точечных данных**.

## 2. Ключевые слова и семантические триггеры

ядерная плотность, kernel density, плотность событий, сглаживание, QGIS Heatmap, ArcMap Kernel Density, ядра, тепловая карта

## 3. Область применения

- **Криминология**: визуализация зон с высокой концентрацией преступлений.
- **Эпидемиология**: картирование очагов заболеваний (например, случаев гриппа).
- **Транспорт**: анализ плотности ДТП или таксопарковок.
- **Экология**: моделирование вероятности встречаемости вида по точкам наблюдения.
- **Градостроительство**: оценка плотности пешеходных потоков или общественного транспорта.
- **Социология**: картирование мест концентрации социальных событий (митинги, фестивали).

## 4. Входные данные

- **Точечный векторный слой** (например, преступления, случаи заболевания).
- **Атрибутивное поле (опционально)**: вес события (например, тяжесть преступления, число заболевших).
- **Радиус поиска (bandwidth)**: определяет степень сглаживания (в единицах CRS).
- **Разрешение выходного растрa**: влияет на детализацию результата.
- **Система координат**: желательно метрическая (для корректного задания радиуса в метрах).

> ⚠️ **Важно**: При отсутствии весового поля все точки считаются равнозначными. Слишком малый радиус создаёт «пиковые» артефакты, слишком большой — чрезмерно сглаживает паттерны.

## 5. Выходные данные

- **Растровый слой** с тем же экстентом, что и область анализа.
- Значения ячеек — **оценка плотности** (единицы зависят от входных данных: например, преступлений/км²).
- Тип данных: обычно **float32**.
- Возможность визуализации через псевдоцветовую шкалу (красный — высокая плотность, синий — низкая).

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Растры → Анализ → Инструменты анализа плотности → Тепловая карта (Heatmap)...
- **Параметры**:
  - Input point layer: точечный слой,
  - Radius: радиус поиска (в единицах CRS),
  - Output raster: путь к выходному файлу,
  - Pixel size: разрешение ячейки,
  - Decay ratio: степень затухания (по умолчанию 0 — равномерное ядро).
- **Особенности**: 
  - Использует квадратичное ядро по умолчанию,
  - Поддерживает весовое поле,
  - Результат можно сразу стилизовать через *Symbology → Render type: Singleband pseudocolor*.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Kernel Density** входит в состав расширения **Spatial Analyst**, которое должно быть активировано (*Customize → Extensions → Spatial Analyst*).

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Spatial Analyst Tools → Density → Kernel Density**.

#### Основные параметры:
- **Input point features**: точечный слой.
- **Population field**: весовое поле (опционально).
- **Output raster**: путь к выходному файлу.
- **Search radius (bandwidth)**: радиус поиска (в единицах CRS).
- **Output cell size**: разрешение ячейки.
- **Area units**: единицы измерения (например, квадратные километры).

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 интерфейс менее гибкий — нет предварительного просмотра.
- Начиная с 10.7, улучшена обработка больших наборов данных (>10 000 точек).
- При работе с File Geodatabase результат более стабилен.
- Инструмент **автоматически рассчитывает рекомендуемый радиус**, если он не задан.

#### Типичные сценарии:
- **Криминальная карта**:  
  Слой = преступления.shp, Радиус = 500 м → тепловая карта преступности.
- **Экологический анализ**:  
  Слой = наблюдения_вида.shp, Радиус = 2000 м → зоны вероятного обитания.

## 8. Ограничения и особенности

1. **Требование к данным**: работает только с **точечными слоями**.
2. **Чувствительность к радиусу**: выбор bandwidth критичен для интерпретации.
3. **Не учитывает барьеры**: не различает, например, реку или дорогу — плотность «перетекает» через них (для этого требуется Cost-based Kernel Density).
4. **Производительность**: время выполнения растёт с увеличением числа точек и уменьшением разрешения.
5. **Интерпретация**: высокая плотность ≠ причинность — требуется дополнительный анализ.

## 9. Научно-методическое обоснование

Метод ядерной плотности был адаптирован для ГИС в 1990-х годах и с тех пор стал стандартом визуализации точечных паттернов. Он реализует принцип **непараметрической оценки плотности** и соответствует подходам пространственного анализа, описанным в работах Silverman (1986) и Longley et al. (2015). В учебниках по ГИС kernel density рассматривается как ключевой метод для выявления скрытых пространственных закономерностей.
