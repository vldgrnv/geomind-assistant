# Упрощение геометрии (Simplify)

## 1. Введение и теоретические основы

Упрощение геометрии (англ. *simplify*) — это операция векторной обработки данных, направленная на **снижение сложности геометрии объектов за счёт уменьшения числа вершин** при сохранении общей формы и топологической корректности. Данная операция реализует принцип **картографической генерализации**, позволяя адаптировать данные к более мелкому масштабу отображения или снизить вычислительную нагрузку при анализе и визуализации.

С математической точки зрения, упрощение решает задачу аппроксимации исходной линии или полигона новой геометрией с меньшим числом точек. Наиболее распространённый алгоритм — **Дугласа–Пекера (Douglas-Peucker, 1973)**, который рекурсивно удаляет вершины, отклонение которых от упрощённой линии не превышает заданного порога (tolerance).

В контексте геоинформационных систем упрощение служит ключевым инструментом для:
- подготовки данных к публикации на веб-картах,
- ускорения рендеринга и анализа,
- снижения объёма файлов при обмене данными,
- соответствия требованиям по масштабу отображения.

Методологически simplify относится к классу **операций генерализации векторных данных** и реализует компромисс между **точностью** и **производительностью**.

## 2. Ключевые слова и семантические триггеры

упрощение геометрии, simplify, генерализация, Douglas-Peucker, снижение детализации, QGIS Simplify, ArcMap Simplify

## 3. Область применения

- **Веб-картография**: уменьшение числа вершин для быстрой загрузки карт.
- **Мобильные приложения**: оптимизация данных для устройств с ограниченными ресурсами.
- **Печать карт**: адаптация к мелкому масштабу (1:500 000 и мельче).
- **Анализ больших данных**: ускорение overlay-операций за счёт упрощения границ.
- **Обмен данными**: сокращение размера файлов при передаче партнёрам.
- **Подготовка к анимации**: снижение нагрузки при динамической визуализации.

## 4. Входные данные

- **Векторный слой** (линии или полигоны; точки не упрощаются).
- **Параметр допуска (tolerance)**: максимальное отклонение упрощённой геометрии от исходной (в единицах CRS).
- **Алгоритм упрощения**: обычно Douglas-Peucker, но могут быть и другие (Visvalingam-Whyatt).
- **Система координат**: желательно метрическая (для интерпретируемого допуска в метрах).

> ⚠️ **Важно**: Слишком высокий допуск может привести к **потере характерных форм** (например, извилистости реки или очертаний острова).

## 5. Выходные данные

- Новый векторный слой с тем же типом геометрии.
- Число вершин значительно снижено (в зависимости от допуска).
- Общая форма объектов сохранена в пределах заданной точности.
- Атрибутивная таблица без изменений.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Вектор → Инструменты геометрии → Упростить...
- **Параметры**:
  - Input layer: исходный слой,
  - Simplification method: Douglas-Peucker (по умолчанию),
  - Tolerance: допуск (в единицах CRS),
  - Output: путь к выходному файлу.
- **Особенности**: 
  - Поддерживает полигоны и линии,
  - Автоматически сохраняет топологическую корректность (без самопересечений),
  - Можно использовать в цепочках обработки (Processing Modeler).

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Simplify Polygon** / **Simplify Line** входит в состав модуля **Cartography Tools → Generalization**.

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите:  
   - Для полигонов: **Cartography Tools → Generalization → Simplify Polygon**  
   - Для линий: **Cartography Tools → Generalization → Simplify Line**

#### Основные параметры:
- **Input Features**: исходный слой.
- **Algorithm**: 
  - *POINT_REMOVE* (Douglas-Peucker),
  - *BEND_SIMPLIFY* (сохранение изгибов).
- **Tolerance**: допуск (в единицах CRS).
- **Output Feature Class**: путь к выходному файлу.

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 интерфейс менее гибкий — нет предварительного просмотра.
- Начиная с 10.7, улучшена обработка сложных полигонов с островками.
- При работе с File Geodatabase результат более стабилен.
- Инструмент **не изменяет исходный слой**, а создаёт новый.

#### Типичные сценарии:
- **Веб-публикация**:  
  Исходный слой = границы_регионов.shp (1 млн вершин) → Simplify с допуском 100 м → 50 тыс. вершин.
- **Печать обзорной карты**:  
  Реки упрощаются для масштаба 1:1 000 000 → сохраняется общее направление, убираются мелкие изгибы.

## 8. Ограничения и особенности

1. **Потеря деталей**: при высоком допуске теряются мелкие, но значимые элементы (мысы, заливы).
2. **Топологические ошибки**: возможны самопересечения при агрессивном упрощении (рекомендуется последующий Repair Geometry).
3. **Не применимо к точкам**: точки не имеют геометрической сложности для упрощения.
4. **Чувствительность к проекции**: допуск в градусах (WGS84) неинтерпретируем — используйте метрическую проекцию.
5. **Производительность**: время выполнения растёт с увеличением числа объектов и сложности геометрии.
