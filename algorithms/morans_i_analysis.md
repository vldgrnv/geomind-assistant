# Пространственная автокорреляция (Moran’s I)

## 1. Введение и теоретические основы

Пространственная автокорреляция (англ. *spatial autocorrelation*) — это статистический метод, направленный на **оценку степени сходства значений признака у соседних объектов** по сравнению со случайным распределением. Основой метода является **глобальный индекс Морана (Moran’s I)**, предложенный Патриком Мораном в 1950 году, который количественно измеряет, насколько близкие в пространстве объекты имеют схожие значения атрибута.

Формула глобального индекса Морана:
\[
I = \frac{n}{W} \cdot \frac{\sum_{i=1}^{n} \sum_{j=1}^{n} w_{ij} (x_i - \bar{x})(x_j - \bar{x})}{\sum_{i=1}^{n} (x_i - \bar{x})^2}
\]
где:
- \( n \) — число объектов,
- \( x_i, x_j \) — значения признака в объектах \( i \) и \( j \),
- \( \bar{x} \) — среднее значение признака,
- \( w_{ij} \) — элемент матрицы пространственных весов (обычно 1, если объекты соседние, иначе 0),
- \( W \) — сумма всех весов.

Интерпретация:
- **\( I > 0 \)** — положительная автокорреляция (похожие значения кластеризованы),
- **\( I < 0 \)** — отрицательная автокорреляция (разные значения чередуются),
- **\( I ≈ 0 \)** — пространственная случайность.

В контексте геоинформационных систем Moran’s I служит ключевым инструментом для:
- проверки гипотезы о пространственной зависимости,
- обоснования использования пространственных моделей (например, регрессии с учётом автокорреляции),
- выявления общих паттернов распределения (например, экономического неравенства, экологических градиентов).

Методологически данный анализ относится к классу **глобальных показателей пространственной зависимости** и требует наличия **векторного слоя с количественным атрибутом**.

## 2. Ключевые слова и семантические триггеры

пространственная автокорреляция, Moran’s I, индекс Морана, spatial autocorrelation, QGIS Moran’s I, ArcMap Spatial Autocorrelation

## 3. Область применения

- **Социальная география**: анализ пространственного неравенства (доходы, образование).
- **Экономика**: выявление кластеров экономической активности.
- **Экология**: оценка градиентов загрязнения или биоразнообразия.
- **Эпидемиология**: проверка гипотезы о кластеризации заболеваний.
- **Градостроительство**: анализ распределения плотности застройки.
- **Криминология**: проверка, сосредоточены ли преступления в определённых районах.

## 4. Входные данные

- **Векторный слой**: точечный или полигональный.
- **Атрибутивное поле**: числовое поле с анализируемым признаком (например, `income`, `crime_rate`).
- **Матрица пространственных весов**: задаётся радиусом поиска или топологическим соседством.
- **Система координат**: желательно метрическая (для корректного задания радиуса в метрах).

> ⚠️ **Важно**: Поле не должно содержать **слишком много одинаковых значений** (например, все нули), так как это делает индекс неинформативным.

## 5. Выходные данные

- **Числовое значение индекса Moran’s I** (от –1 до +1).
- **z-оценка** и **p-значение** для оценки статистической значимости.
- **Текстовая интерпретация**: «положительная автокорреляция», «отрицательная автокорреляция» или «случайное распределение».
- Возможность экспорта результатов в таблицу или отчёт.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Обработка → Инструментарий анализа → Global Moran’s I...
- **Требуется плагин**: **Spatial Statistics** или **PySAL** (встроен в Processing Toolbox).
- **Параметры**:
  - Input layer: исходный слой,
  - Input field: атрибутивное поле,
  - Distance band: радиус анализа (в единицах CRS),
  - Output: текстовый файл с результатами.
- **Особенности**: 
  - Поддерживает только глобальный индекс (для локального — Local Moran’s I),
  - Использует PySAL для расчётов,
  - Результат выводится в консоль и файл.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Spatial Autocorrelation (Global Moran’s I)** входит в состав расширения **Spatial Statistics Tools**, доступного через **ArcToolbox**.

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Spatial Statistics Tools → Analyzing Patterns → Spatial Autocorrelation (Global Moran’s I)**.

#### Основные параметры:
- **Input Feature Class**: исходный слой.
- **Input Field**: атрибутивное поле.
- **Conceptualization of Spatial Relationships**: 
  - *INVERSE_DISTANCE*,
  - *FIXED_DISTANCE_BAND*,
  - *CONTIGUITY_EDGES_ONLY* (для полигонов).
- **Distance Band**: радиус анализа (автоматически рассчитывается, но можно задать вручную).

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 интерфейс менее гибкий — нет предварительного просмотра.
- Начиная с 10.7, улучшена обработка больших наборов данных (>10 000 объектов).
- При работе с File Geodatabase результат более стабилен.
- Инструмент **автоматически определяет оптимальный радиус**, если он не задан.

#### Типичные сценарии:
- **Экономический анализ**:  
  Слой = районы.shp, Поле = `median_income` → I = 0.42, p < 0.01 → богатые районы кластеризованы.
- **Экологический мониторинг**:  
  Слой = станции.shp, Поле = `pollution_level` → I = 0.35 → загрязнение имеет пространственный паттерн.

## 8. Ограничения и особенности

1. **Требование к данным**: необходимо достаточное число объектов (>30) для статистической значимости.
2. **Чувствительность к радиусу**: выбор матрицы весов влияет на результат.
3. **Не указывает местоположение кластеров**: только глобальную тенденцию (для локализации — Local Moran’s I).
4. **Производительность**: время выполнения растёт квадратично с числом объектов.
5. **Интерпретация**: значимый I ≠ причинно-следственная связь — требуется дополнительный анализ.
