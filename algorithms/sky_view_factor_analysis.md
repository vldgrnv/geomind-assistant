# Коэффициент открытости неба (Sky View Factor, SVF)

## 1. Введение и теоретические основы

Коэффициент открытости неба (англ. *Sky View Factor, SVF*) — это параметр рельефа, характеризующий **долю видимого небосвода из данной точки на поверхности земли** с учётом окружающего рельефа. Значения SVF лежат в диапазоне от **0.0** (полностью закрыто горизонтом, например, в узком каньоне) до **1.0** (полностью открытое небо, например, на плоской равнине).

С геометрической точки зрения, SVF рассчитывается как интеграл по полусфере над точкой:
\[
\text{SVF} = \frac{1}{2\pi} \int_{0}^{2\pi} \int_{0}^{\pi/2} V(\theta, \phi) \cdot \cos\theta \cdot \sin\theta \, d\theta \, d\phi
\]
где \( V(\theta, \phi) \) — функция видимости (1, если направление свободно, 0 — если заблокировано рельефом), \( \theta \) — зенитный угол, \( \phi \) — азимут.

На практике SVF аппроксимируется через дискретные направления (например, 16 или 32 лучей) и используется для оценки:
- солнечной радиации,
- ночного охлаждения,
- микроклимата городских улиц,
- термического комфорта.

В контексте геоинформационных систем SVF служит ключевым инструментом для **климатического и энергетического моделирования**, особенно в условиях сложного рельефа или плотной застройки.

Методологически данный анализ относится к классу **операций анализа прямой видимости и затенения**, тесно связанных с *Viewshed* и *Hillshade*, но ориентированных на **полусферическую интеграцию**.

## 2. Ключевые слова и семантические триггеры

коэффициент открытости неба, sky view factor, SVF, микроклимат, солнечная радиация, QGIS Sky View Factor, ArcMap нет прямого аналога

## 3. Область применения

- **Городской климат**: оценка солнечного доступа и теплового комфорта в уличных каньонах.
- **Энергетика**: расчёт потенциала солнечной энергии для установки панелей.
- **Экология**: моделирование микроклимата под пологом леса.
- **Архитектура**: проектирование зданий с учётом естественного освещения.
- **Сельское хозяйство**: оценка инсоляции склонов для выбора культур.
- **Туризм**: анализ условий для наблюдения за звёздным небом.

## 4. Входные данные

- **Цифровая модель рельефа (ЦМР)** в виде растрa (GeoTIFF, GRID, IMG).
- **Разрешение**: чем выше, тем точнее расчёт SVF в условиях сложного рельефа.
- **Система координат**: проекция должна быть в **линейных единицах (метрах)**.
- **Опционально**: растр высот зданий (для городского анализа — DSM вместо DEM).

> ⚠️ **Важно**: Для городских территорий рекомендуется использовать **цифровую модель поверхностей (DSM)**, включающую здания и деревья. Для природных ландшафтов достаточно ЦМР (DEM).

## 5. Выходные данные

- Новый растр того же разрешения и экстента, что и исходная ЦМР.
- Значения ячеек: от **0.0** (полностью закрыто) до **1.0** (полностью открыто).
- Тип данных: обычно **float32**.
- Возможность визуализации через псевдоцветовую шкалу (синий → красный).

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Растры → Анализ → Инструменты анализа рельефа → Sky View Factor...
- **Альтернатива**: использовать **SAGA GIS → Terrain Analysis → Sky View Factor** через Processing Toolbox.
- **Параметры**:
  - Input layer: ЦМР или DSM,
  - Number of directions: число лучей (по умолчанию 16),
  - Max distance: максимальное расстояние анализа (опционально),
  - Output: путь к выходному файлу.
- **Особенности**: 
  - Поддерживает только растровые входные данные,
  - Использует метод дискретных лучей (discrete ray-tracing),
  - Результат можно сразу использовать в **Solar Radiation** или **Thermal Comfort** моделях.

### 6.2. ArcMap (версии 10.4–10.8)

В ArcMap **отсутствует прямой инструмент Sky View Factor**. Однако его можно эмулировать:

#### Вариант A: Через **Viewshed + интеграцию**
1. Создать 16–32 точек вокруг каждой ячейки (через скрипт),
2. Выполнить **Viewshed** для каждого направления,
3. Усреднить результаты.

#### Вариант B: Использовать **внешние инструменты**
- Экспортировать ЦМР в **SAGA GIS** или **GRASS GIS**,
- Выполнить расчёт SVF,
- Импортировать результат обратно в ArcMap.

#### Особенности:
- В ArcMap 10.4–10.8 рекомендуется использовать **QGIS или SAGA** для расчёта SVF.
- При использовании DSM важно корректно задать разрешение и проекцию.

#### Типичные сценарии:
- **Городской анализ**:  
  Input = dsm_city.tif → SVF → выявление «тёмных» улиц с низким солнечным доступом.
- **Солнечная энергетика**:  
  Input = dem_hills.tif → SVF → выбор мест для установки панелей (SVF > 0.7).

## 8. Ограничения и особенности

1. **Чувствителен к разрешению**: низкое разрешение занижает вариацию SVF.
2. **Не учитывает атмосферу**: облака, рефракция не моделируются.
3. **Для городов требуется DSM**: DEM даёт завышенные значения SVF.
4. **Производительность**: время выполнения растёт с увеличением числа лучей и размера ЦМР.
5. **ArcMap-ограничение**: отсутствие прямого инструмента усложняет работу.
