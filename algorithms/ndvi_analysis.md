# Нормализованный разностный вегетационный индекс (NDVI)

## 1. Введение и теоретические основы

Нормализованный разностный вегетационный индекс (англ. *Normalized Difference Vegetation Index, NDVI*) — это фундаментальный спектральный индекс дистанционного зондирования Земли, предназначенный для **количественной оценки состояния и плотности растительного покрова**. NDVI основан на различии в отражательной способности здоровой растительности в видимом (красном) и ближнем инфракрасном (NIR) диапазонах электромагнитного спектра.

Математически NDVI вычисляется по формуле:

\[
\text{NDVI} = \frac{\text{NIR} - \text{Red}}{\text{NIR} + \text{Red}}
\]

где:
- **NIR** — отражательная способность в ближнем инфракрасном канале,
- **Red** — отражательная способность в красном канале.

Значения NDVI лежат в диапазоне от **–1.0 до +1.0**:
- **–1.0 … 0.0**: вода, облака, снег, пустыня,
- **0.1 … 0.3**: редкая растительность, кустарники,
- **0.3 … 0.6**: умеренная растительность (поля, луга),
- **0.6 … 0.9**: густая, здоровая растительность (леса, тропики).

В контексте геоинформационных систем NDVI служит ключевым инструментом для:
- мониторинга сельскохозяйственных угодий,
- оценки последствий засухи или пожаров,
- картографирования типов растительности,
- анализа динамики зелёного покрова в урбанизированных территориях.

Методологически NDVI относится к классу **спектральных индексов**, рассчитываемых через **растровый калькулятор** или специализированные инструменты.

## 2. Ключевые слова и семантические триггеры

NDVI, вегетационный индекс, дистанционное зондирование, спутниковые данные, растительность, QGIS NDVI, ArcMap NDVI

## 3. Область применения

- **Сельское хозяйство**: оценка состояния посевов, определение зон стресса.
- **Лесное хозяйство**: мониторинг здоровья лесов, выявление вырубок.
- **Экология**: анализ динамики растительного покрова в заказниках.
- **Градостроительство**: оценка «зелёности» городских районов.
- **Управление ЧС**: оценка последствий пожаров, засух, наводнений.
- **Климатология**: долгосрочный мониторинг изменений биомассы.

## 4. Входные данные

- **Мультиспектральное изображение** (GeoTIFF, IMG, GRID) с как минимум двумя каналами:
  - **Красный (Red)** — обычно канал 3 (Landsat 8/9) или 4 (Sentinel-2),
  - **Ближний ИК (NIR)** — обычно канал 5 (Landsat 8/9) или 8 (Sentinel-2).
- **Атмосферная коррекция**: рекомендуется использовать данные уровня **Surface Reflectance** (SR), а не Top of Atmosphere (TOA).
- **Система координат**: любая проекция, но желательно метрическая для последующего анализа.

> ⚠️ **Важно**: Каналы должны быть **геометрически совмещены** и иметь одинаковое разрешение. При необходимости — выполнить **Resample**.

## 5. Выходные данные

- Новый растр с тем же разрешением и экстентом, что и входные данные.
- Значения ячеек: от **–1.0 до +1.0** (обычно float32).
- NoData-значения сохраняются там, где исходные каналы содержали NoData.
- Результат можно визуализировать через цветовую шкалу (например, от коричневого к зелёному).

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Растры → Анализ → Калькулятор растра...
- **Выражение**:("NIR@1" - "Red@1") / ("NIR@1" + "Red@1")
- **Параметры**:
- Input layers: два канала (Red и NIR),
- Output layer: путь к файлу NDVI.tif,
- CRS: наследуется от входных данных.
- **Особенности**: 
- Можно использовать готовый плагин **Semi-Automatic Classification Plugin (SCP)** для автоматического расчёта,
- Поддерживает маскирование облаков (если есть слой маски).

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **NDVI** доступен в двух формах:

#### Вариант A: Через **Raster Calculator** (Spatial Analyst)
1. Активируйте *Spatial Analyst* (*Customize → Extensions*).
2. Откройте **ArcToolbox → Spatial Analyst Tools → Map Algebra → Raster Calculator**.
3. Введите выражение: Float("NIR" - "Red") / Float("NIR" + "Red")

#### Вариант B: Через **Band Arithmetic** (Image Analyst, начиная с 10.7)
1. Активируйте *Image Analyst*.
2. Перейдите: **Image Analyst Tools → Math → Band Arithmetic**.
3. Выберите метод **NDVI**, укажите Red и NIR каналы.

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 нет прямого инструмента NDVI — только через Raster Calculator.
- Начиная с 10.7, добавлен **Band Arithmetic** с предустановленными индексами.
- При работе с большими изображениями рекомендуется использовать **mosaic dataset** или **image service**.
- Результат можно сразу классифицировать через **Reclassify** (например, 0.0–0.3 → «слабая», 0.3–0.6 → «средняя» и т.д.).

## 8. Ограничения и особенности

1. **Требование к данным**: нужны именно **Red и NIR каналы** — не работает с RGB-изображениями.
2. **Чувствительность к атмосфере**: без атмосферной коррекции значения могут быть искажены.
3. **Насыщение**: при очень высокой биомассе (тропические леса) NDVI «насыщается» и перестаёт различать изменения.
4. **Не учитывает структуру растительности**: не различает деревья и траву при одинаковом NDVI.
5. **Облачность**: требует маскирования облаков, иначе результат будет некорректным.
