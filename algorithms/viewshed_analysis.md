# Зона видимости (Viewshed)

## 1. Введение и теоретические основы

Зона видимости (англ. *viewshed*) — это операция растрового анализа, направленная на **определение всех ячеек цифровой модели рельефа (ЦМР), видимых из одной или нескольких точек наблюдения** с учётом рельефа местности. В отличие от простого буфера, viewshed учитывает **препятствия**, создаваемые рельефом: холмы, горы, овраги, которые могут блокировать прямую линию обзора.

С геометрической точки зрения, алгоритм viewshed для каждой ячейки проверяет, пересекает ли прямая линия от точки наблюдения до центра ячейки какую-либо другую ячейку с более высокой высотой. Если пересечение есть — ячейка **невидима**, если нет — **видима**.

В контексте геоинформационных систем зона видимости служит ключевым инструментом для:
- размещения наблюдательных постов, вышек связи, ветрогенераторов,
- оценки визуального воздействия объектов (например, новых зданий),
- планирования туристических маршрутов с панорамными видами,
- военного анализа (зоны контроля местности).

Методологически viewshed относится к классу **операций анализа прямой видимости (line-of-sight analysis)** и требует наличия **гидрологически корректной ЦМР** (без артефактных впадин).

## 2. Ключевые слова и семантические триггеры

зона видимости, viewshed, анализ видимости, прямая видимость, QGIS Viewshed, ArcMap Viewshed

## 3. Область применения

- **Телекоммуникации**: выбор мест для установки вышек сотовой связи.
- **Энергетика**: размещение ветрогенераторов с учётом визуального воздействия.
- **Градостроительство**: оценка визуальной доминанты новых зданий.
- **Туризм**: проектирование смотровых площадок и панорамных маршрутов.
- **Военное дело**: определение зон наблюдения и контроля местности.
- **Охрана природы**: минимизация визуального воздействия инфраструктуры в заказниках.

## 4. Входные данные

- **Цифровая модель рельефа (ЦМР)** в виде растрa (GeoTIFF, GRID, IMG).
- **Точки наблюдения**: точечный слой с координатами (может содержать поля высоты глаз наблюдателя и высоты целевого объекта).
- **Параметры наблюдения**:
  - Высота глаз наблюдателя над поверхностью (по умолчанию 1.75 м),
  - Высота целевого объекта (по умолчанию 0 м),
  - Максимальное расстояние видимости (опционально),
  - Вертикальный угол обзора (опционально).
- **Система координат**: проекция должна быть в **линейных единицах (метрах)**.

> ⚠️ **Важно**: ЦМР не должна содержать NoData-значений в зоне интереса. Артефактные впадины могут создавать ложные «слепые зоны».

## 5. Выходные данные

- Новый растр того же разрешения и экстента, что и исходная ЦМР.
- Значения ячеек:
  - **1** — видима,
  - **0** — невидима,
  - **NoData** — вне зоны анализа.
- Тип данных: обычно **uint8**.
- Возможность конвертации в полигоны для картографического оформления.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Растры → Анализ → Инструменты анализа рельефа → Зона видимости...
- **Альтернатива**: использовать **GRASS r.viewshed** через Processing Toolbox.
- **Параметры**:
  - Input layer: ЦМР,
  - Observer points: точечный слой,
  - Observer height: высота глаз (м),
  - Target height: высота цели (м),
  - Maximum distance: максимальное расстояние (м),
  - Output: путь к выходному файлу.
- **Особенности**: 
  - Поддерживает несколько точек наблюдения за один запуск,
  - Использует эффективный алгоритм на основе лучей (ray-casting),
  - Результат можно сразу стилизовать через *Paletted/Unique values*.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Viewshed** входит в состав расширения **Spatial Analyst**, которое должно быть активировано (*Customize → Extensions → Spatial Analyst*).

#### Доступ к инструменту:
1. Откройте **ArcToolbox**.
2. Перейдите: **Spatial Analyst Tools → Visibility → Viewshed**.

#### Основные параметры:
- **Input raster**: цифровая модель рельефа.
- **Input point observer features**: точечный слой наблюдателей.
- **Output raster**: путь к выходному файлу.
- **Observer offset**: высота глаз наблюдателя (поле в атрибутивной таблице или константа).
- **Target offset**: высота целевого объекта.
- **Maximum distance**: максимальное расстояние видимости.

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 интерфейс менее гибкий — нет предварительного просмотра.
- Начиная с 10.7, улучшена обработка больших ЦМР (>10 000 × 10 000 пикселей).
- При работе с высоким разрешением возможны ошибки нехватки памяти — рекомендуется использовать **scratch workspace** на быстром диске.
- Результат автоматически добавляется на карту; его можно использовать в **Line of Sight** для детального анализа.

#### Типичные сценарии:
- **Телекоммуникации**:  
  Точки = вышки.shp, Высота глаз = 30 м → зона покрытия сигнала (без учёта зданий).
- **Туризм**:  
  Точки = смотровые площадки.shp, Высота глаз = 1.75 м → панорамные зоны.

## 8. Ограничения и особенности

1. **Не учитывает объекты выше рельефа**: здания, деревья, мосты — только ЦМР.
2. **Чувствителен к разрешению ЦМР**: низкое разрешение завышает видимость, высокое — создаёт шум.
3. **Производительность**: время выполнения растёт с увеличением размера ЦМР и числа точек.
4. **Требует метрической проекции**: иначе расстояния и высоты будут искажены.
5. **Не учитывает атмосферную рефракцию**: для точных военных расчётов требуется коррекция.
