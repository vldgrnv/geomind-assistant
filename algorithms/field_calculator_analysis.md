# Калькулятор полей (Field Calculator)

## 1. Введение и теоретические основы

Калькулятор полей (англ. *field calculator*) — это фундаментальная операция атрибутивной обработки векторных данных, направленная на **вычисление новых значений атрибутов или модификацию существующих с использованием математических, логических, текстовых и геометрических функций**. Данная операция позволяет трансформировать «сырые» данные в аналитически значимые показатели без экспорта в сторонние приложения.

С методологической точки зрения, field calculator реализует принцип **декларативного программирования над атрибутивными таблицами**: пользователь задаёт выражение, которое последовательно применяется к каждой строке таблицы. Выражение может включать:
- арифметические операции (`+`, `-`, `*`, `/`),
- логические условия (`if`, `case when`),
- функции работы со строками (`upper`, `replace`),
- геометрические свойства (`$area`, `$length`),
- ссылки на другие поля (`"population" / "area"`).

В контексте геоинформационных систем калькулятор полей служит ключевым инструментом для:
- нормализации данных (например, плотность населения = население / площадь),
- классификации объектов по условиям,
- преобразования единиц измерения,
- создания производных индексов (например, коэффициент застройки),
- подготовки данных для визуализации и анализа.

Методологически данная операция относится к классу **атрибутивных преобразований** и является неотъемлемой частью любого ГИС-проекта.

## 2. Ключевые слова и семантические триггеры

калькулятор полей, field calculator, вычисление атрибутов, атрибутивная обработка, QGIS Field Calculator, ArcMap Field Calculator

## 3. Область применения

- **Демография**: расчёт плотности населения по районам.
- **Градостроительство**: вычисление коэффициента застройки (площадь зданий / площадь участка).
- **Экология**: нормализация выбросов на единицу площади.
- **Экономика**: расчёт среднего дохода на душу населения.
- **Кадастр**: преобразование площади из гектаров в квадратные метры.
- **Логистика**: вычисление времени в пути по скорости и расстоянию.

## 4. Входные данные

- **Векторный слой** любого типа геометрии (точки, линии, полигоны).
- **Атрибутивная таблица** с числовыми, текстовыми или датированными полями.
- **Выражение** на языке, поддерживаемом ГИС:
  - В QGIS: синтаксис на основе Python/SQL,
  - В ArcMap: синтаксис на основе VBScript/Python (в зависимости от версии).
- **Целевое поле**: существующее или новое (с указанием типа данных: целое, дробное, текст).

> ⚠️ **Важно**: При работе с геометрическими функциями (площадь, длина) слой должен быть в **метрической проекции**, иначе результат будет некорректным.

## 5. Выходные данные

- Обновлённая атрибутивная таблица исходного слоя.
- Новое или изменённое поле с вычисленными значениями.
- Тип данных поля соответствует логике выражения (например, деление → float).
- Операция выполняется **in-place** (изменяет исходный слой), поэтому рекомендуется резервное копирование.

## 6. Программная реализация

### 6.1. QGIS (версия 3.28+)
- **Путь**: Открыть таблицу атрибутов → Заголовок поля → «Вычислить поле» (или Ctrl+I).
- **Особенности интерфейса**:
  - Поле ввода выражения с подсветкой синтаксиса,
  - Список функций слева (геометрия, строки, математика, дата),
  - Предварительный просмотр результата для первой строки,
  - Возможность создать новое поле прямо в диалоге.
- **Примеры выражений**:
  - Плотность: `"population" / $area * 1000000` (на км²),
  - Классификация: `if("slope" > 15, 'steep', 'gentle')`,
  - Преобразование: `round("area_ha", 2)`.

### 6.2. ArcMap (версии 10.4–10.8)

Инструмент **Field Calculator** доступен через контекстное меню поля в таблице атрибутов.

#### Доступ к инструменту:
1. Откройте **Attribute Table** слоя.
2. Щёлкните правой кнопкой по заголовку поля → **Field Calculator**.

#### Основные параметры:
- **Expression**: поле для ввода формулы.
- **Parser**: выбор языка — **VBScript** (по умолчанию в 10.4–10.6) или **Python** (рекомендуется, доступен во всех версиях).
- **Code Block**: опциональный блок для сложной логики (функции, циклы).
- **Field**: целевое поле (должно быть заранее создано через **Add Field**).

#### Особенности версий 10.4–10.8:
- В ArcMap 10.4–10.6 по умолчанию используется **VBScript**, что ограничивает функциональность.
- Начиная с 10.7, интерфейс стал более дружелюбным, но Python остаётся мощнее.
- При работе с геометрией в Python: `!shape.area!`, `!shape.length!`.
- **Обязательно**: поле должно быть заранее создано нужного типа (float, text и т.д.).

#### Типичные выражения:
- Плотность (Python): `!population! / !shape.area! * 1000000`

8. Ограничения и особенности
Тип поля: нельзя записать дробное число в целочисленное поле — требуется предварительное создание поля нужного типа.
Проекция: геометрические функции ($area, !shape.area!) требуют метрической проекции.
Язык сценариев: в ArcMap 10.4–10.6 VBScript ограничен — рекомендуется использовать Python.
Производительность: при большом числе объектов (>100 000) расчёт может занимать время.
Необратимость: операция изменяет исходный слой — всегда делайте резервную копию.
